# 0001. 신(SCN)·자동 지능(iAuto/Superior Auto)·검출(얼굴/스마일/소프트스킨/오토프레이밍)

> 상태: **static-derived**(libObj/CautionConfig 심볼·문자열 + scalar SDCom 표) + **spec-cross**(Sony ILCE-5000 help guide). 좌표: `packages/data/re/scalar/*.tsv`, `packages/data/re/ida/{libObj,CautionConfig}.so.*`, `packages/data/re/menu/main_menu_tree.txt`(전부 gitignore). 공개본은 behavior+offset만.

이 문서는 "장면을 **인식/선택**하고, 피사체(얼굴·스마일)를 **검출**하고, 결과를 **합성/표시**"하는 계열을 end-to-end로 매핑한다. 공통 모델은 [focus/0001](../focus/0001.%20focus-system.md)과 동일하다: **엔진(av-cam/MPR/Detect 채널)이 인식·검출·합성을 소유**하고, **ObjRenderer가 프레임/아이콘을 영상·표시 평면에 직접 렌더**하며, 뷰(UI)는 모드를 **set**하고 상태를 **read**할 뿐이다.

제어면 3층(= focus 문서와 동일 구분):
1. **SDCom param**(`CameraSetParameters 0x1003`, id 256~388) / **SDCom 메시지**(0x10xx) — 외부 제어면, route-b in-proc SDCom으로 직접 가능.
2. **CVPDM eventId**(CmnViewProcessDataMgr W1 group, 메뉴 노드가 쓰는 경로) — 뷰-독립 read/write.
3. **엔진 PARAMID/MSGID**(libObj ObjCamera/ObjCameraAgent/ObjFaceRecorder/ObjRenderer 내부) — SDCom/CVPDM에 안 뜨는 것들.

## 1. iAuto(인텔리전트 오토) / Superior Auto(프리미엄 오토)

### 1.1 모드 진입
- funcEventMode **7** = iAuto/프리미엄 오토([camera/0001](../camera/0001.%20funcevent-mode-enum.md)). 최상위 노출모드 축이다.
- 메뉴 노드: `IAutoModeRoot` → `IAutoModeIntelligentAuto` / `IAutoModeSuperiorAuto` (자동모드 설정 노드, Intelligent=0 / Superior=1 — [shooting/0001 §3 인접] 와 동일 토글).
- ShootingMode 축: `ShootingModeStillIntelligentAuto` / `ShootingModeSuperioirAutoMode`(철자 원본 그대로).
- SDCom 경로: Superior는 `exposureMode`(**param 263**) enum 값 중 하나(`s_exposureMode` 값표가 런타임 .bss라 수치는 device-only, 기준바디 현재 M=19). iAuto도 같은 param 263 축.

### 1.2 장면 인식(scene recognition)
- 인식 결과 = **PARAMID_SCENE_NUM**(libObj). 추가로 `MprIf::GetHighlightSceneInfo(MPR::HighlightSceneInfo*)` — **MPR 서브시스템이 인식 엔진**이다(av-cam 통계를 MPR이 장면 분류로 변환). 즉 인식 로직은 Sony 독점, 우리가 재현/변경 불가.
- 장면 아이콘 이벤트: **CameraEventAutoSceneModeEventList = 0x2**(push) / **CameraEventAutoSceneModeParamList = 0x12c3**(값). 클라이언트가 0x2 수신 시 0x12c3을 Get하면 현재 인식된 장면 번호가 온다 → 우리 OSD가 장면 아이콘을 그릴 수 있는 유일한 입력.
- 인식 장면 클래스(Sony ILCE-5000 help guide 교차): Portrait / Backlight Portrait / Night Portrait / Infant(유아) / Macro / Landscape / Backlight / Night Scene / Tripod Night Scene / Spotlight / Low Brightness 계열. **Portrait/Backlight Portrait/Night Portrait/Infant 는 얼굴검출이 Off면 인식 안 됨**(help guide 명시) → 장면 인식이 얼굴 검출 입력에 부분 의존.

### 1.3 Superior Auto 다중프레임 합성
- iAuto와의 차이 = **여러 장을 찍어 합성/최적 1장 추출**. 제어:
  - `SuperiorAutoSettingsContShooting`(연속촬영 Auto/Off) — 합성용 연사 허용.
  - `SuperiorAutoSettingsImageExtract`(이미지 추출 Auto/Off) → 엔진 PARAMID **PARAMID_AUTO_ADVANCE_IMAGE_EXTRACT**, `MSGID_SET_AUTO_ADVANCE_IMAGE_EXTRACT_CMD`. 엔진이 연사 중 최적 프레임을 골라 저장.
  - 합성 모드 자체(Hand-held Twilight / Auto HDR(역광) / Slow Sync / Daylight Sync / Slow Shutter / 연속촬영)는 **엔진이 장면에 따라 자동 선택** — HDR/HHT 합성 파이프라인은 av-cam/MPR 독점(HDR과 동일, [shooting/0002] 룩 파이프라인처럼 재현 불가).
- 즉 Superior Auto의 "여러 장→1장"은 드라이브/릴리즈([shooting/0001 §2])처럼 **엔진 시퀀서가 소유**. 우리는 Settings enum만 선택.

## 2. SCN(신 선택) 모드

### 2.1 진입 + 제어 id
- funcEventMode **8** = SCN(실기 측정, [camera/0001]).
- 최상위 노출모드는 역시 **param 263 exposureMode**의 SCN 값. SCN "안의 개별 신"은 별도 축:
  - 메뉴 노드 `SceneSelectionRoot` → 개별 신 노드(§2.2).
  - 엔진 param: **DefObjCamera::PARAMID_SCENE_SELECT**(libObj).
  - 상태 이벤트: **CameraEventSceneModeParamList = 0x1211**(SCN 현재 신 값; push EventList는 없고 ParamList만 → Get/구독으로 read).
- **CVPDM group eventId**: 메뉴 노드 `CmnViewSettingNodeSceneSelection`이 W1 group로 쓴다(focus의 group13 패턴과 동일 구조). 정확한 group 번호는 캐시에 없음 → **IDA-TODO**(settings_tree `13=` 덤프 또는 Wrapper getter RE).

### 2.2 개별 신 enum (CautionConfig 노드)
CautionConfig.so property-list에 존재하는 신(= 플랫폼 superset):
Portrait · Sports(+AdvanceSports) · Macro · Landscape · Sunset · NightView/NightScene · NightPortrait · HandHeldTwilight · AntiMotionBlur · HighSensitivity · Gourmet · Pet · FireWorks · Beach · Snow · SoftSkin · SoftSnap · BackgroundDefocus · BackLightHDR.
- **a5000 실제 노출(stock) SCN 9종**(Sony ILCE-5000 사양 + [menu/0002]): 인물 / 스포츠 / 매크로 / 풍경 / 노을 / 야경 / 손持야경(Hand-held Twilight) / 야경인물 / 인물흐림방지(Anti Motion Blur). 나머지(Gourmet/Pet/Beach/Snow/HighSens/SoftSkin/SoftSnap/BackgroundDefocus/BackLightHDR/AdvanceSports)는 **CautionConfig에만 있는 상위기종 superset**으로 a5000 메뉴에선 게이트 off. (정확한 device 노출 enum·순서 = device-confirm.)
- 각 신이 "잠그는" 것: 신 선택은 노출모드(P/A/S 고정)·드라이브(예: 스포츠=연속, HHT/AntiMotionBlur=내부 연사합성)·플래시·DRO/ISO 상한을 **엔진이 프리셋으로 강제**. 개별 잠금값은 런타임 적용이라 device-dump로만 확정(미확정).
- **HandHeldTwilight / AntiMotionBlur** 는 SCN 안의 신이면서 내부적으로 Superior Auto와 같은 **다중프레임 합성**을 쓴다(엔진 독점).

## 3. 얼굴 검출(Face Detection) + 등록·우선순위

### 3.1 제어 id
- **SDCom param 304 `faceScanMode`**(0x1003 read/set, 기준값 1) = 얼굴검출 모드.
- **SDCom param 303 `displayFaceFrame`** = 얼굴 프레임 표시 on/off.
- **SDCom 메시지 0x1015 / 0x1016 `CameraSetFaceDetection`**(request param **49**, Int) — 전용 set 메시지.
- 엔진 PARAMID: `PARAMID_FACE_DETECTION_MODE`(+ `_ACT` 실적용값, `PARAMID_INTERNAL_FACE_DETECTION_MODE`), `PARAMID_IS_FACE_DETECT_ON`, 우선순위 `PARAMID_FACE_PRIORITY_TRACKING_MODE`, AE/AF 연동 `PARAMID_FACE_AUTO_CONTROL`, 선택/커서 `PARAMID_FACE_SELECT`·`PARAMID_FACE_CURSOR_MODE`·`PARAMID_FACE_ID`.
- 엔진 MSGID: `ObjCamera::MSGID_SET_FACE_DETECTION_MODE_CMD`, `MSGID_SET_FACE_PRIORITY_TRACKING_MODE_CMD`.
- 모드 상태 이벤트: **CameraEventFaceDetectionModeParamList = 0x12a6**.
- 메뉴 노드: `FaceDetect_SmileShutterRoot`(얼굴검출+스마일을 한 노드로 묶음) — 값: `FacDetOff` / `ON_NoPriority`(얼굴검출 on, 등록얼굴 우선 X) / `ON_PriorityOnResisteredFace`(등록얼굴 우선) / `SmileShutterOn`.

### 3.2 검출이 도는 곳
- **OBJAVBBCBASECLASS::DetectCh::startFaceDetection(FDT::ApiScalarAStartFaceDetectionParam*, ...)** + `DetectCh::registDetectCallback` — 얼굴 검출은 libObj의 **Detect 채널(av-cam/Scalar 검출 유닛)**에서 돈다. RC 리사이즈 **이전** 통계단계(= focus AF 통계와 같은 지점, [imaging/0001 §2]) → ch51 라이브뷰 버퍼와 독립.
- 결과를 MPR로: `MprIf::SetRecFaceDetectionParam(MprIf::FaceDetectParam*, ulong)`. 앱 통지: **`MSGID_FACE_DETECT_EVT`**(libObj: "Receive -> MPR <MSGID_FACE_DETECT_EVT>", "Notify -> APP <MSGID_FACE_DETECT_EVT>").
- SDCom 레벨 얼굴 이벤트: **CameraEventFaceDetectedEventList = 0x1e01**(push). (0x1e01은 focus-start 리스트에도 들어있는 범용 "피사체 검출" 이벤트. 좌표 payload 구조·왕복 msgId는 device-capture 필요.)
- 프리뷰 검출: **CameraEventPreviewDetectedEventList = 0x19** / 리뷰 `CameraEventAutoReviewInfoEventList = 0x1300 0x19`.

### 3.3 얼굴 프레임이 OSD로 가는 경로
- **엔진 렌더가 그린다**(우리 ch53 아님). `OBJRENDERER::ExecCommandSetFaceFrame` / `SequenceSetFaceFrameCmd` / `ExecCommandSetFaceFrameCommonDesign` / `...OptionDesign`, 로컬 메시지 `MSGID_RENDERER_SET_FACE_FRAME_CMD`(= `DefObjRenderer::MSGID_SET_FACE_FRAME_CMD`).
- 표시 평면 선택 PARAMID: `PARAMID_FACE_FRAME_OUT_DISP`, 출력별 제외 `PARAMID_FACE_FRAME_EXCLUSION_DISPOUT_{EVF,LINE,PANEL}`·`_ONOFF`·`_TEMPRORARY`(원본 철자). → 엔진이 PANEL/LINE/EVF 각 출력에 프레임을 직접 그리며 어디에 그릴지도 엔진이 결정. **focus 프레임/피킹과 완전 동일 모델.**
- 즉 촬영 중 얼굴 프레임은 **순정 OSD passthrough로 자동 표시**된다([route-b-stock-osd-passthrough] 메모리와 일치). 우리가 직접 그리려면 0x1e01/MSGID_FACE_DETECT_EVT 좌표를 받아 ch53에 오버레이해야 하는데, 그럴 필요가 없다(엔진이 이미 그림).

### 3.4 얼굴 등록(face registration) 저장소
- **FaceRecorder 서브시스템**(libObj, `ObjFaceRecorder`). 시퀀스: `SequenceFaceRecord`(등록), `SequenceFaceDelete` / `SequenceAllFaceDelete`(삭제), `SequenceFacePriorityChange`(우선순위), `SequenceFaceListDisplayStart/CancelStart`(등록목록 표시), `SequenceSyncReqRecordedFaceNum`(등록 수 조회), `SequenceStillCaptureParam`, `SequenceSetFaceFrame`.
- MSGID: `MSGID_FACE_RECORD_CMD/CMP`, `MSGID_FACE_DELETE_CMD`, `MSGID_ALL_FACE_DELETE_CMD`, `MSGID_FACE_PRIORITY_CHANGE_CMD`, `MSGID_FACE_LIST_DISPLAY_START/CANCEL_START_CMD`, `MSGID_SYNC_REQ_RECORDED_FACE_NUM_CMD`, `MSGID_NOTIFY_FACE_REGISTERED_EVT`, `MSGID_NOTIFY_RECORDED_FACE_NUM_EVT`, `MSGID_REGIST_FACE_CLEAR_CMD`, `ObjCamera::MSGID_FACE_RECORD_CAPTURE_START_CMD`.
- 등록얼굴 **매칭 엔진** = 별도 DLL: `modelIndivRecognition.so` / `modelIndivRecognitionCap.so` / `modelIndivRecognitionEdit.so`(개인 인식/캡처/편집). 등록 데이터는 av-cam/MPR측 영속 저장(개인정보 → packages/data 밖 금지, device-private).

## 4. 스마일 셔터 + 감도

- 메뉴: `FaceDetect_SmileShutterRoot` 안에 `SmileShutterOn` + 감도 **3단계 `Slight`(약간) / `Normal`(보통) / `Big`(활짝)**.
- 엔진 PARAMID: `PARAMID_SMILE_SHUTTER_MODE`(+`_SET`/`_ACT`), 에이전트 경유 `PARAMID_AGENT_SMILE_SHUTTER_MODE`(+`_SET`/`_ACT`), 감도 `PARAMID_SMILE_DETECTION_SENSITIVITY`(+`_SET`).
- MSGID: `ObjCameraAgent::MSGID_SET_SMILE_SHUTTER_MODE_CMD`, `MSGID_SET_SMILE_DETECTION_SENSITIVITY_CMD`.
- 검출: 얼굴 검출(DetectCh)의 하위 — 스마일 판정도 av-cam/Detect 채널. 릴리즈 트리거는 **엔진이 스마일 임계 도달 시 자동 셔터**(앱이 셔터 안 누름, 셀프타이머와 동형 — [shooting/0001 §3]).
- OSD: 스마일 게이지/프레임도 엔진 렌더. ObjRenderer `BKID_DISPLAY_SMILE_{COLOR,DOUBLE_FRAME,LOCKED_COLOR,LOCKED_DOUBLE_FRAME,REGIST_COLOR,REGIST_DOUBLE_FRAME,REGIST_LOCKED_*,REGIST_OUT_AF_*}` = 스마일/등록얼굴 프레임 색·이중테두리 디자인. 동영상 인코더도 `faceSmileInfoAddress`/`faceSmileSampleTime` 보유.
- SDCom 직접 param은 없음(304 faceScanMode가 얼굴검출 축, 스마일은 엔진 PARAMID/메뉴노드 경로).

## 5. 소프트 스킨 효과(Soft Skin)

- **SDCom param 355 `softSkinEffect`**(0x1003, 기준값 1) = 직접 set 가능.
- 상태 이벤트: **CameraEventSoftSkinEffectParamList = 0x135e**.
- 검출/적용 엔진: `OBJAVBBCBASECLASS::DetectCh::beautyEffectDetection(FDT::ApiStartArtfilterDetectionParam*, FDT::ArtfilterCompParam*)` — **얼굴검출 기반 뷰티 이펙트**가 Detect 채널에서 돈다(artfilterDetection과 한 쌍). 스킨 IF `LkmSkinIF::Create`.
- 합성: `OBJEFFECT::BeautyEffect*`(SequenceAppExecBeautyEffectCmd, BeautyEffectLayout, SequenceAppGetBeautyEffectFaceInfoCmd, SequenceChildExtractFaceImageCmd, SequencePinDeliverBeautyEffect, ExecCmdSdfBeautyEffect). PARAMID `PARAMID_BEAUTY_EXTRACT_FACE_ID`·`PARAMID_FACE_CLIP_MARGIN`. → 얼굴을 추출해 피부를 매끄럽게 하는 **별도 Artfilter 처리 시퀀스**([shooting/0002 §픽처이펙트]와 동일 Artfilter 계열). 룩 자체는 엔진 독점, 우리는 레벨 enum만 선택.
- 주의: `SceneSelectionSoftSkin`(SCN 신)과 param 355 `softSkinEffect`(독립 효과)는 별개 축.

## 6. 오토 오브젝트 프레이밍 (a5000 = "PortraitIFraming")

- 메뉴 노드 이름: **`PortraitIFraming`**(얼굴검출/추적 메뉴 그룹 안, `FaceDetect_SmileShutter` 바로 옆). a5000 UI 표기 "Auto Obj. Framing".
- 엔진 param: **PARAMID_AUTO_FRAMING_MODE**(+`_SET`/`_ACT`). VALUEID: `AUTO_FRAMING_OFF/ON`, 그리고 프레이밍 유형 `AUTO_FRAMING_{AUTO,PORTRAIT,MACRO,LANDSCAPE,TRACKING}`, 캡처모드 `SR_CAP_MODE_AUTO_FRAMING`.
- MSGID: `DefObjCamera::MSGID_SET_AUTO_FRAMING_MODE_CMD`, 통지 `MSGID_NOTIFY_AUTO_FRAMING_MODE_EVT` + **`MSGID_NOTIFY_AUTO_FRAMING_AREA_EVT`**(계산된 트리밍 영역 통지).
- 영역 계산: `pvt_CalcAutoFramingArea` → `PARAMID_AUTO_FRAMING_{X,Y,W,H}` + `pvt_SetAutoFramingAreaValidity`. **엔진이 피사체(얼굴/매크로 대상)를 보고 크롭 사각형을 자동 계산**.
- 결과물: 원본 + **트리밍된 2차 이미지**를 캡처 시 저장, 메이커노트에 기록(`MkNoteAutoFramingInfo`, M_SinglePbBase). → HDR/HHT처럼 **엔진 독점 캡처 후처리**.
- SDCom param(256~388)엔 없음 → 엔진 PARAMID/메뉴노드 경로만. CVPDM group은 IDA-TODO.

| 오토 오브젝트 프레이밍 | 메뉴노드 PortraitIFraming, PARAMID_AUTO_FRAMING_MODE, MSGID_SET_AUTO_FRAMING_MODE_CMD | pvt_CalcAutoFramingArea(엔진) | 엔진(크롭 영역 통지 + 2차 이미지 저장) | ✅ on/off set 가능; 크롭 계산·저장=엔진 |

범례: ✅ 설정 경로 확정(정적) · 🔶 설계상 엔진에 위임/read만 · ⚠️ 가능하나 미배선.

**권장 통합 모델**(focus/shooting과 일관):
- 모드/토글(iAuto·Superior·SCN 신·얼굴검출·스마일·소프트스킨·오토프레이밍)은 **우리 메뉴/퀵바에서 set**. 최우선 경로 = SDCom(304/303/355, 0x1015/16) 있는 건 SDCom, 없는 건 CVPDM group(focus group13 패턴) 또는 엔진 PARAMID.
- **인식·검출·합성·프레임 렌더는 전부 순정 엔진에 위임.** 촬영 중 얼굴/스마일 프레임, 장면 아이콘, 오토프레이밍 크롭은 **순정 OSD passthrough**로 그대로 나온다 → 우리가 ch53에 다시 그릴 필요 없음.
- 우리 OSD가 장면 아이콘을 **직접** 표시하고 싶을 때만 이벤트(0x2+0x12c3) read-overlay. 얼굴 좌표(0x1e01)도 원하면 read 가능하나 엔진이 이미 그리므로 비권장.
