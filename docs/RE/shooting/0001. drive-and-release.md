# 0001. 드라이브/릴리즈 — 싱글·연속·셀프타이머·브래킷

> 상태: **derived**(SDCom 메시지/param 표 정적 도출) + **observed**(일부 param GetParameters 실측). 좌표: `packages/data/re/scalar/{message_ids,camera_params,request_params}.tsv`(gitignore). 엔진 심볼은 libObj.so 네임 테이블.

촬영 "방법"(언제·몇 장·어떤 간격으로 셔터를 떨어뜨리는가). SDCom param id 축은 256~388, set은 `CameraSetParameters`(0x1003, IntArray, request param id 52).

---

## 1. 드라이브 모드 제어 파라미터 (CameraGetParameters 0x1002 / SetParameters 0x1003)

| param id | 이름 | 역할 | 실측(기준바디) |
|---|---|---|---|
| **318** | driveMode | 싱글/연속/셀프타이머/브래킷 **모드 선택** (enum) | 0 |
| **319** | driveBurstMax | 연속 촬영 **최대 장수** 상한 | 1 |
| **320** | driveBurstSpeed | 연속 **레이트**(Hi/Lo 등 enum) | 0 |
| **321** | driveCaptureStopEnable | 연속 중 **정지 허용** 플래그 | 0 |
| **322/323** | bracketMode / bracketMode2 | 브래킷 종류(연속/단일/WB/DRO) | 1 / 0 |
| **324** | bracketStepNum | 브래킷 **장수**(3/5…) | 3 |
| **325** | bracketStepEV | 브래킷 **스텝 EV**(0.3/0.5/0.7 ×10 추정) | 3 |
| **326** | bracketOtherStep | WB/DRO 브래킷의 폭 단계 | 0 |
| **327** | bracketOrder | 브래킷 **순서**(0→-→+ 등) | 0 |
| **328** | selfTimer | 셀프타이머 **초/매수** enum | 0 |

- enum 수치(driveMode의 각 값, driveBurstSpeed Hi/Mid/Lo 등)는 **런타임 .bss 값표**(`s_ADParamKeyConvTable`의 값표 심볼)로, 정적으로는 수치 확정 불가 → **메뉴 토글 + 라이브 GetParameters 덤프**로 확정해야 한다(device-only). Sony 순정 메뉴상 존재하는 값 자체는 stock-menu 인벤토리 기준.
- driveMode·burstMax·burstSpeed·bracket* 모두 **camera 키 표에 존재** → `0x1003`으로 set **가능**(피킹/제브라처럼 표 밖인 항목과 다름).

## 2. 릴리즈/시퀀싱 흐름 (엔진이 소유)

촬영 트리거 자체는 SDCom 명령이지만, **몇 장을·어떤 간격으로 떨어뜨릴지는 엔진이 시퀀싱**한다(앱/UI가 프레임마다 트리거하지 않음).

- 단발: `AutoFocus 0x1006` → `TakePicture 0x1008` → `StopTakePicture 0x1027`.
- 연속(버스트): `TakePicture` 유지 동안 엔진이 driveBurstSpeed 간격으로 반복 릴리즈, driveBurstMax/버퍼 여유까지. 버스트 결과는 엔진의 **MPR 서브시스템이 "burst shot group"으로 묶는다** — 심볼: `MprIf::GetBurstShotGroupCount`, `MprIf::{Begin,Run,End}ConvertBurstShotGrpToCondition`, 내부 핸들러 `HndlBurstshotGrp…`/`SetBurstshotType`. 버스트 레이트의 실제 상한은 **센서 읽기 + RAW 버퍼(dmm) 할당 + SA 유닛 free**에 걸린다(imaging/0003 §4) → 버퍼가 차면 레이트가 떨어지는 건 엔진 메모리 레이아웃 소관, 재현/변경 불가.
- `CamseqSetReleaseLock 0x0123`(release lock) + `CamseqSetRawCapture 0x0120` + `CamseqStoreImage 0x0122`가 캡처 시퀀스의 하위 제어(릴리즈 잠금/RAW 캡처 지정/이미지 저장) — CameraSequence 패밀리.

## 3. 셀프타이머

- 전용 메시지: **`CameraStartSelfTimer 0x1020` / `CameraStopSelfTimer 0x1021`**(request param 없음, 트리거만). 배타 처리 `SelfTimerExclusion 0x102b`.
- **카운트다운 소스 = 엔진**. `selfTimer`(param 328)로 초/매수를 정하고, start 메시지 후 **엔진이 카운트다운과 LED/비프를 구동**한다(libObj 심볼 `In CountDown Can…` 등 countdown 상태 문자열). 앱은 초를 세지 않는다.
- route-b 함의: 셀프타이머 OSD 카운트 표시가 필요하면 엔진 카운트다운 이벤트를 SDCom 이벤트 구독(event 카테고리)으로 받아야 하며, 자체로 카운트하면 안 된다(엔진 릴리즈 타이밍과 어긋남).

## 4. route-b 통합 판정

| 기능 | 설정 경로 | 판정 |
|---|---|---|
| 드라이브 모드/버스트 max/speed/stop | `0x1003` param 318~321 | **우리 UI에서 set 가능** |
| 브래킷(연속/WB/DRO) 모드·장수·EV·순서 | `0x1003` param 322~327 | **set 가능** |
| 셀프타이머 값 | `0x1003` param 328 + 릴리즈는 `0x1020/0x1021` | **set 가능** |
| 버스트 그룹핑/레이트 상한/버퍼 | MPR + dmm + SA (엔진) | **관측만, 변경 불가(Sony 독점)** |
| 릴리즈 타이밍/카운트다운 | 엔진 시퀀서 | **엔진 소유, 이벤트 구독으로 표시만** |

**권장 모델**: 드라이브/브래킷/셀프타이머 "설정값"은 route-b 메뉴에서 `0x1003`으로 쓰고, **릴리즈·시퀀싱·카운트다운은 순정 엔진에 맡긴다**(촬영 중은 순정 OSD passthrough — stock-osd-passthrough 메모리와 일치). 우리가 직접 N장 트리거를 흉내 내지 않는다.

## 5. device-only 미확정

1. driveMode / driveBurstSpeed / selfTimer / bracket* **enum 수치**(런타임 .bss) — 메뉴 토글+GetParameters 덤프로 확정.
2. 연속 중 실제 버퍼 깊이·레이트 저하 곡선(기기 실측).
3. 셀프타이머 카운트다운 **이벤트 id**(event 카테고리와 교차 확인 필요).
