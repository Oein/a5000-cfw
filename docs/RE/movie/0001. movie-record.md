# 0001. 동영상 녹화 파이프라인 (record / encode / mux / audio)

상태: 정적 분석 확정(로컬 Hex-Rays 캐시 `packages/data/re/ida/libObj.so` + SDCom 카탈로그 `packages/data/re/scalar/` + 에뮬 RE 문서 `RE_AUDIO.md`/`RE_SA_DSP.md`). SA DSP 실인코드·일부 param enum·0x300A 페이로드는 **디바이스 확인 필요**(§7 명시).

주소 표기: `libObj+X` = `/usr/lib/libObj.so` IDA 오프셋(base 0). av-cam는 절대 VA(load 0x43541000, Thumb). 공개 가능한 동작·오프셋만; 원시 디컴파일은 `packages/data/re/`(gitignore).

## 0. 요약

| 질문 | 답 |
|---|---|
| 컨테이너/코덱 | **AVCHD**(.MTS/.M2TS, **H.264** 영상 + **Dolby AC-3** 또는 LPCM 오디오) 와 **MP4**(**MPEG-4 AVC/H.264** + **AAC-LC**). XAVC-S 비대상. |

| route-b | **순정 엔진 유지 + SDCom 토글/트리거 + ch53 OSD 오버레이**. 인코드/mux 재구현 금지(SA DSP 전용 펌웨어). |

## 1. 제어면 (control knobs)

### 1.1 SDCom Movie 팩토리 (0x3000~0x300C)
`libScalarDaemon` CommandProcessor (근거 `packages/data/re/scalar/message_ids.tsv`, `request_params.tsv`):

| id | 명령 | param | 비고 |
|---|---|---|---|
| 0x3000 | `MovieConnectMedia` | Int | 녹화 대상 미디어 연결(선행 단계로 추정) |
| 0x3001 | `MovieDisconnectMedia` | — | |
| **0x3002** | **`StartMovieRecording`** | — | 녹화 시작 |
| **0x3003** | **`StopMovieRecording`** | — | 녹화 정지 |
| 0x300A | `MovieSetParameters` | IntArray | 포맷/기록설정 등 |
| 0x300B | `MovieGetParameters` | — | |
| 0x300C | `MovieGetSupportedParameters` | — | 지원 값 |

Audio 팩토리(0x3100 `AudioSetParameters`(IntArray) / 0x3101 Get / 0x3102 GetSupported)는 §4.

추가 CameraEx: `CameraSetRecordingMedia 0x1026`(param 53, SD 슬롯), UI `UIGetMovieButtonMode 0x080C`(MOVIE 버튼 동작 모드).

### 1.2 설정 노드 (UI/Backup, 엔진 게이트)
viewUnified 문자열(`viewUnified*.so.strings.tsv`):
- `cmnViewSettingNodeRootMovieFileFormat` — **File Format**: AVCHD / MP4 (영문 `1e04e129/12a`, `1e04e262` "MP4").
- 기록설정 노드 — **Record Setting**(`1e04e85c`): 위 FX/FH/PS 목록.
포맷/기록설정은 Backup.bin에 영속되고 엔진이 인코더 열 때(`EncOpen2`) 참조한다. SDCom param id 축(256~388)에는 포맷 전용 키가 노출되지 않음 → 변경은 `MovieSetParameters 0x300A` 또는 설정노드 경로(실측 필요, §7).

## 2. 녹화 상태머신 (derived)

```
MOVIE 버튼 / StartMovieRecording 0x3002
  → ObjMovieRecorder (modelMovieRec.so, ModelMovieRecToInstance)        libObj+0x30e5a Create
  → InfMovieEncoder: PreEncStart (PinReqConnect + IntEnc + EncOpen)
        → EncOpen2  … codecId/codecId2/fileFormat/fileFormat2 결정       [InfBase]RID_AVIF_MPRNTFY_ENC_OPEN2_COMP
        → Packaged_EncStart2 (MC_Enc)                                    영상/오디오 인코드 개시
  → SA DSP ZIMA H.264 인코드 (av-cam, sa_avce_*_zma.bin)
  → MC/SDF mux → SD 기록 (이벤트 0x2102 StartWriting)
Stop:
  StopMovieRecording 0x3003
  → Packaged_EncStop2 → EncThm(썸네일) → CompleteWriting(0x2102)
```

**듀얼 REC**: `EncOpen2`가 `codecId`/`codecId2`, `fileFormat`/`fileFormat2` 두 벌을 가짐 → AVCHD(메인)+MP4(서브) 동시 녹화. `MprIf::SetMp4CompositeConfig`, `GetDualRecMovieMaxBitrate`, `SuperResolutionDualRec` 심볼이 이를 뒷받침.

### 2.1 녹화 이벤트 (`packages/data/re/scalar/event_tables.tsv`)
| 이벤트 리스트 | 구성 id | 의미 |
|---|---|---|
| `MovieEventStartRecordingEventList` | 0x2101 | 녹화 시작 |
| `MovieEventStopRecordingEventList` | 0x2101 | 녹화 정지 |
| `MovieEventStartWritingEventList` | 0x2102 | 파일 쓰기 시작 |
| `MovieEventCompleteWritingEventList` | 0x2102 | 쓰기 완료 |
| `MovieEventRecTimeEventList` | 0x2101 0x2104 | 경과시간 |
| `MovieEventRecRemainEventList` | 0x2106 | 잔여 녹화시간 |

`event_dispatch.tsv`: `0x201f`/`0x201b` → `handleRecordingMediaChange`. 녹화 상태/시간은 SDCom RegisterEvent로 구독(촬영 OSD에 표시).

## 3. 영상 인코드 (H.264)

- 엔진 측 **`InfMovieEncoder`**(libObj `InfBase`/`InfMovieEncoder` 심볼, offset 대역 `libObj+0xaf4f44~0xaf61e5`)가 인코더 세션을 연다:
  - `ExecCmd_MC_EncWfiOpen`/`EncWfiStart`/`EncWfiClose` — WFI(라이터) 파일 세션.
  - `ExecCmd_MC_EncOpenSpeedup`/`EncCloseSpeedup` — 빠른 재개용 선열기.
  - `ExecCmd_MC_Packaged_EncStart2`/`EncStop2` — 실제 인코드 start/stop (영상+오디오 묶음).
  - `ExecCmd_MC_EncThm` — 녹화 썸네일 인코드.
  - `[InfBase]RID_AVIF_MPRNTFY_ENC_OPEN2_COMP codecId fileFormat` — 열림 완료 통지에 코덱/컨테이너 식별값 동반(값 enum은 .bss 런타임 → 실측 필요).
- 실제 **H.264 압축 연산은 SA DSP ZIMA**에서 수행(디코드의 `sa_avcd_*_zma.bin` 대칭쌍 = `sa_avce_*_zma.bin`). 매니저 task 44(av-cam `439232BC`, queue 0x101) 프로토콜: open(0x21)/load(0x22)/start(0x41·0x44)/close(0x23), 완료는 소스-A IRQ(51/54/61/64)로 복귀(에뮬 `RE_SA_DSP.md`). 즉 **인코드는 Sony 전용 SA 펌웨어**, Linux는 메일박스 제어만.
- 프로파일/레벨은 SA 인코더 프로그램·EncOpen2 파라미터에 내재(정적 enum 미노출). 비트레이트는 기록설정(FX=24M, FH=17M, PS=28M …)으로 결정.

## 4. 오디오 (마이크 / 레벨 / 윈드노이즈)

근거: 에뮬 `RE_AUDIO.md` §1~§2.2 + libObj `AVBIZ::UNIVERSE::AdfCh`/`AVBIZ::MIC::BackendController` 심볼.

### 4.1 캡처 경로
- 내장 **스테레오 마이크 → 내장 ADC → AudioIp 캡처 링**(PA 0xF3420000, ch0/1). 외부 코덱(ABB/HIBIKI)은 코드상 존재하나 a5000에선 비활성(`sub_438B87DC` 스텁=0).
- 캡처 PCM → **SA DSP `AvcEncAudioModule`**(`TskAvcAudio1Thread2Instance`)에서 인코드: `sa_aaclcenc_nr.bin`(AAC-LC+NR, MP4), `sa_dd51enc_nr.bin`(Dolby AC-3+NR, AVCHD), `sa_integenc_nr.bin`.

### 4.2 녹음 레벨 (control: 설정노드 + SDCom Audio 0x3100)
- 설정노드: `cmnViewSettingNodeRootMovieAudioRecordingLevel`, `...AudioRecordingLevelDisplay`, `cmnViewSettingNodeRootMicrefLevel`(영문 "Micref Level" `1e04f541`).
- 엔진 래퍼: `WrapperAudioRecordingLevel::get/setAudioRecordingLevel`, 레벨 미터 모델 `ModelAudioLevelMeter`(라이브 레벨 표시).
- SDCom: `AudioSetParameters 0x3100`(IntArray)로 토글 가능(Audio 파라미터 축). 정확한 param index·수치범위는 실측 필요(§7).

### 4.3 윈드노이즈 / 저역컷
- 설정노드: `cmnViewSettingNodeRootMovieWindNoiseReduction`("Wind Noise Reduct." `1e04ebdf`).
- 엔진: `AdfCh::InSetWindNr`(`libObj+0x18267`) / `AdfCh::InSetLowCut`(`+0x17ecc`) / `AdfCh::InNtfyWindNr`(`+0x16938`) → AudioIp 내부 IIR 필터 계수(0xF3423000 대역, `RE_AUDIO.md` §1.1). `BackendController::Process_BbLowCutModeByInputSource`가 입력원별 저역컷 모드.
- 이벤트: `AudioEventLowCutEventList`(0x1f00).

## 5. route-b 통합 모델 (녹화)

- **인코드/mux 재구현 금지**: H.264·오디오 인코드는 SA DSP ZIMA 전용 펌웨어 상주 + av-cam 메일박스 프로토콜 + MC/SDF/MWF mux. 주입 프로세스에서 재현은 공수·위험 모두 비현실적이고 `minimal-sony-footprint`(Sony 영상/엔진 SW 그대로) 원칙에도 어긋남.
- **권장(촬영 패스스루와 동일, `route-b-stock-osd-passthrough`)**:
  1. 우리 UI가 MOVIE 트리거 시 SDCom `MovieConnectMedia 0x3000`(필요시)→`StartMovieRecording 0x3002`, 종료 시 `StopMovieRecording 0x3003` 호출.
  2. 포맷/기록설정/오디오는 `MovieSetParameters 0x300A`/`AudioSetParameters 0x3100` 또는 순정 설정노드 경로(실측 결과에 따라).
  3. 녹화 중 영상은 순정이 ch51(VDF YUV 평면)에 그림. 우리는 ch53 OSD만(REC 인디케이터·경과/잔여시간·오디오 레벨미터·우리 컨트롤패널). 상태/시간은 SDCom RegisterEvent(0x2101/0x2102/0x2104/0x2106) 구독.
- **벽돌-안전**: 모두 휘발 SDCom/엔진 상태. 포맷을 Backup.bin에 영속하려면 메뉴-쓰기 whitelist 범위 내에서만([backup](../backup/README.md)).

## 6. 번호 네임스페이스 주의
- SDCom **메시지 id**(0x3002 등) ≠ SDCom **param id**(256~388, §0002 참조) ≠ **설정노드 id** ≠ Backup propId. 포맷은 설정노드/Backup, start/stop은 메시지 id, 손떨림/줌은 param id(→ [0002](0002.%20steadyshot-and-zoom.md)).

## 7. 디바이스 확인 필요 (device-only unknowns)
1. `StartMovieRecording 0x3002` 전제조건: `MovieConnectMedia 0x3000`의 Int param 값(미디어 식별), 라이브뷰 중/동영상 모드-트리 전환 없이도 바로 되는지.
2. `MovieSetParameters 0x300A` 페이로드: fileFormat/recSetting의 param index와 enum 값(AVCHD vs MP4, FX/FH/PS 수치). `EncOpen2`의 `codecId`/`fileFormat` enum 실측.
3. `AudioSetParameters 0x3100` 레벨/윈드NR param index·값범위, `MicrefLevel` 수치.
4. 에뮬은 null-SA라 실제 인코드 파일이 생성되지 않음 → 실기에서만 MTS/MP4 산출·비트레이트·오디오 코덱 검증.
5. route-b에서 SDCom만으로 녹화 트리거 시 입력 소유권/크래시/모드-트리 정합(촬영 패스스루와 동일 리스크).
6. 듀얼 REC(AVCHD+MP4) 동시성과 `GetDualRecMovieMaxBitrate` 실제 상한.
