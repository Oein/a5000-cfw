상태: 정적 분석 확정(로컬 Hex-Rays 캐시 `packages/data/re/ida/libObj.so` + SDCom camera param 표 `packages/data/re/scalar/camera_params.tsv` + 에뮬 `RE_LENS_EMOUNT.md`). 줌 배율값·OSS 세부 타이밍·전자식 크롭비는 **디바이스 확인 필요**(§5). 공개 가능한 동작·오프셋만.

## 1. SteadyShot (손떨림 보정)

### 1.1 a5000은 바디 IS 없음 → 정지 = 렌즈 OSS
- 정지 SteadyShot은 **렌즈 OSS(Optical SteadyShot)** 로만 동작. 바디 내 센서시프트 IS 하드웨어 없음.
- OSS 유닛은 렌즈 쪽에 있고 바디는 **UART1(E-mount 통신)** 로 활성/명령을 전달(렌즈 구동 주체는 av-cam Mount 모듈, 에뮬 `RE_LENS_EMOUNT.md` §0: 렌즈는 av-cam이 구동, UART1 750k/1.5M baud).
- 고장 메시지 `"SteadyShot unit has malfunctioned"`(`1e04f08a`)는 렌즈/바디 연동 OSS 유닛을 지칭.
- control: `CameraSetParameters 0x1003` param **331 `steadyShotStill`**(실측 기본값 2). 값표는 .bss 런타임(on/off 등).
- UI: `cmnViewSettingNodeRootStillSteadyShot`, `WrapperStillSteadyShot::get/setStillSteadyShot`, `ViewRecSteadyShot`. 영문 "Still: SteadyShot"(`1e04ec8b`), on/off(`1e04e27c/27d`).

### 1.2 동영상 SteadyShot = OSS + 전자식
- 동영상은 **렌즈 OSS + 전자식 보정**을 결합. 전자식은 **화각을 크롭**하고(활성 모드) 프레임을 흔들림에 맞춰 이동/회전시킨다. 근거 문자열:
  - `1e04ef08`류: "SteadyShot을 켜면 **화각이 렌즈 전체 화각보다 좁아진다**"(= 전자식 크롭).
  - `1e04ef1a`: "끄면 렌즈 전체 화각으로 촬영 가능"(크롭 해제).
  - `1e04f24a`: "**회전 보정 포함** SteadyShot"(Intelligent Active 상당), 강도 "stronger"/"strongest"(`1e04efdb`/`1e04f53b`).
- 전자식 보정은 **gyro** 입력을 쓴다: `PARAMID_GYRO_ANGLE`(`ObjRenderer SequenceAppSetGyroAngleCmd`, "First Gyro Angle Event min/angle/max"), 보정 상수 `C_GYRO_GAIN`/`S_GYRO_REF_GAIN`/`A_GYRO_SENS`. `SRJudge Stabilizer changed`/`pvt_ChangeFrameLockSteadyShotParam`/`ActionSetFrameLockSteadyShot`가 프레임락(전자식 안정화) 적용 경로.
- control: param **372 `steadyShotMovie`**. UI `cmnViewSettingNodeRootMovieSteadyShot`, "Movie: SteadyShot"(`1e04ec8c`).
- 재생측 메타: `M_SinglePbBase_Utils ... ImageStabilizer : %d,%d`(녹화시 안정화 상태가 파일 메타에 기록).

### 1.3 route-b
- 정지/동영상 모두 `CameraSetParameters 0x1003` param 331/372로 **직접 토글 가능**(SDCom, 휘발=벽돌안전). OSS 명령·전자식 크롭 연산은 순정 엔진이 수행. 우리는 토글만 하고 OSD에 상태만 표시.

## 2. 줌 — 세 종류

줌 설정 노드 "Zoom Setting"(`1e04f51f`)은 3택:
- **Optical zoom only**(`1e04f564`/f571) — 광학만.
- **On:ClearImage Zoom**(`1e04f56b`/f537) — 광학 + 클리어이미지(초해상).
- **On:Digital Zoom**(`1e04f531`) — 광학 + 클리어이미지 + 디지털(최대 10x, `1e04e583`).

줌은 단계적으로 **광학 → 클리어이미지 → 디지털** 순으로 넘어간다(광학 한계 도달 후 전자식 영역 진입).

### 2.1 광학 줌 (파워줌 / PZ)
- E PZ 16-50 등 파워줌 렌즈: 렌즈 내 **PZ 모터**를 바디가 **UART1**로 구동. 비-PZ 렌즈는 수동 링(바디 구동 없음).
- control:
  - 물리 레버: `KEY_LENS_ZOOM_LEVER`, `KEY_POS_ZOOMFOCUS_SW`(libObj 키 심볼).
  - SDCom: **`CameraStartZoom 0x102E`**(param id 1..8 = 줌 속도/방향 단계로 추정) / **`CameraStopZoom 0x102F`**. 오토줌 `0x1039/0x103A`.
  - 상태: `PARAMID_LENS_ZOOM_STATUS`("Power Zoom Status changed"), 이벤트 `CameraEventPowerZoomEventList`/`...ParamList`(0x12c6), dispatch `0x2028/0x2029 handlePowerZoomEvent`. 위치 `CameraEventZoomPositionEventList`.
- param: **`343 zoomDriveType`**(실측 2 = 줌 구동 타입).

### 2.2 클리어이미지 줌 (초해상, by-pixel super-res)
- 광학 배율 소진 후 **엔진 초해상 필터**로 배율 연장(디지털 줌보다 화질 우수). "clear image technology"(`1e04ece1`).
- 기구: 엔진 SDF **`SequenceFilterSuperResolutionCmd`**(`ObjScalar`), `m_SuperResolutionZoomProc.m_ProcStart`, `pvt_SetSuperResolutionZoomProc`, `AllocMem And SuperResolution`. 듀얼REC용 `SuperResolutionDualRec`.
- control: param **`345 superResolutionZoomMode`**(실측 0=off). 설정/적용 경로 `pvt_ChangeSuperResolutionParam`, `pvt_SetParamEZoomSuperResolutionMode`.
- 종료 통지 `ZoomMagClearImageEnd`.

### 2.3 디지털 줌 (crop + upscale)
- 단순 **크롭+업스케일**(화질 저하). 최대 10x(`1e04e583`). 광학+클리어이미지 소진 후 영역.
- control: param **`346 precisionZoomMode`**(실측 0), `SetDigitalZoom 0x1030`(param 102), 리셋 `CameraResetDigitalZoom 0x1031`, `CameraProcessSpinalZoom 0x1035`.
- 연관: **`344 smartZoomMode`** = 스마트줌(이미지 크기보다 작게 설정 시 센서 크롭으로 무열화 배율) — 디지털줌과 구분.

### 2.4 배율 스테핑 & 상태
- 전자 배율은 **EZoom(Electronic Zoom) magnification**으로 추적: `EZoomMagnification Set/Act changed`, `ActionExeResetEzoomMagnification`, `EZoomSuperResolutionMode`. 재생 메타 `EZoomRatio : %d,%d,%d`.
- `SetInitZoomRatio`가 진입 배율 설정, 이벤트 `CameraEventMaxDigitalZoomMagEventList`(최대 배율), `CameraEventPrvwMagInfo/PrvwMagChanged`(프리뷰 확대 정보).
- `GetPreviewMagnificationRatio`(reply id 106) — 현재 배율 조회.

### 2.5 줌 라이브뷰 평면
- 광학/클리어이미지/디지털 결과 영상은 모두 **VPH ch51(VDF YUV)** 라이브뷰 평면에 나온다(재생영상·라이브뷰와 동일 평면, 에뮬 `RE_DISPLAY_SCANOUT.md`). 초해상/크롭은 엔진이 ch51로 가는 YUV에 적용. 별도 GPU 비디오 평면이나 OSD 평면(ch53)이 아님. 배율 표시(숫자/바)만 OSD(ch53).

### 2.6 route-b
- 세 줌 모두 SDCom으로 구동 가능: 광학 `CameraStartZoom 0x102E`/`StopZoom 0x102F`, 디지털 `SetDigitalZoom 0x1030`, 모드 게이트 param 344/345/346(`CameraSetParameters 0x1003`). 초해상/크롭 연산과 PZ 모터 구동은 순정 유지. 우리 UI는 줌 입력(레버/버튼)을 SDCom 명령으로 변환 + 배율 OSD만 ch53에 그림.

## 4. 번호 네임스페이스 주의
- SDCom param id(331/372/343~346) ≠ SDCom 메시지 id(0x102E 등) ≠ 설정노드 id ≠ Backup propId. SteadyShot/줌모드는 param id, 줌 start/stop은 메시지 id.

## 5. 디바이스 확인 필요 (device-only unknowns)
1. `CameraStartZoom 0x102E` param 1..8의 정확한 의미(속도 단계? 방향?), 파워줌 렌즈 장착 시 실제 모터 구동 확인.
2. param 331/372/344/345/346 값 enum(on/off/강도단계, 동영상 SS standard/active/intelligent-active).
3. 동영상 전자식 SteadyShot의 화각 크롭 배율(standard vs active)과 gyro 회전보정 여부 실측.
4. 비-PZ(수동) 렌즈에서 전자줌(클리어이미지/디지털)만 동작하는지.
5. 줌/SteadyShot 변경 시 ch51 라이브뷰 즉시 반영·입력 소유권(route-b 패스스루 리스크).
6. 에뮬 가상렌즈는 OSS/PZ 미모델 → 광학줌·OSS는 실기 전용(가상렌즈는 `RE_LENS_EMOUNT.md` §0 "mounted but dead").
