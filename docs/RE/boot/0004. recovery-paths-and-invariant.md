# 0004. 복구 경로와 복구 불변식

> 상태: 업데이터 플래그 경로 **derived**(실기 리허설 미검증), 불변식은 에뮬레이터(NAND 클론) 검증.

## 복구 경로
- **업데이터 모드 플래그 = `/setting/updater/mode` 파일**(nflasha2). `/usr/bin/up.sh`가 생성하며 다음 부팅이 UFP 모드로 간다. USB 명령(PMCA `CMD_SWITCH_MODE 0x30`) 처리기 `libupdaterufp.so`도 `up.sh user`를 실행한다.
- 루트 셸이 있으면 USB 없이도 `touch /setting/updater/mode; sync; reboot`로 업데이터에 진입 가능(실기 미검증).
- 업데이터 코어(nflasha1)와 부트로더는 펌웨어 업데이트로 **기록되지 않는다** → 메인 파티션이 깨져도 업데이터는 남는다. 정상 상태에서 `/setting/updater`에는 `comp`, `dat4`만 있고 mode 플래그는 없다.
- 디버그 부팅: `/setting/mode/dmode`(`change_mode.sh`) 값 0/g/d/e, `/setting/env.txt` 환경 주입([0003](0003.%20autostart-via-dmode-and-env.md)).
- 부팅 모드 판단(`/proc/udm/upm_bootmode`: ADJUST/BIS)은 커널/upm 모듈이라 펌웨어 파일에 없어 미분석.

## 복구 생명선과 함정
- **생명선**: `nflasha1`(자체 커널+initrd를 가진 updater 코어, `/system`·`/usr`·Android 미참조) + `nflasha2`(`updater/mode` 플래그 + Backup). `/usr`, Android, `/system`을 모두 지워도 **플래그가 이미 설정되어 있으면** updater는 부팅한다.
- **함정**: updater는 플래그를 세팅해야만 진입할 수 있고, 그 소프트 경로는 USB SWITCH_MODE(메인 펌웨어가 USB와 `up.sh`를 돌릴 정도로 살아 있어야 함) 또는 루트 셸이다. "검정 화면 + USB 열거 안 됨" 상태에 도달하면 둘 다 사라지고, 비-플래그 부트로더 진입(키 홀드/부팅 실패 카운터)만 남지만 이는 **미확인**(부트로더 미모델링, 실기 시험 필요).

## 불변식
**교체/CFW는 updater 도달 능력(USB 또는 셸)을 절대 없애면 안 된다.** 이를 보장 못 하는 설계는 벽돌 티어이며 증명 전까지 에뮬레이터 전용이다. 실기에는 UART가 없으므로 CFW/배포는 전부 USB 기반이고 에뮬 UART 셸은 개발 전용.

## 부팅 시간 수용 기준
커스텀 UI(주입 포함)의 부팅 시간은 순정 **이하**여야 한다(에뮬레이터 게스트 시간 A/B로 증명). 상쇄 수단: (1) 대체하는 순정 UI 억제로 초기화 비용 제거, (2) 빠른/지연 주입 진입(첫 프레임에 필요한 작업만 먼저), (3) 스냅샷/HOT 부트. Sony의 영상·엔진 처리는 그대로 유지한다.
