# 0003. 부팅 시 자동 실행 — dmode + env.txt

> 상태: **observed**(에뮬레이터에서 확정; 실기에서는 OpenMemories-Tweak이 같은 방식으로 자동 시작). 2026-11-17.

## 메커니즘
a5000은 ptrace 없이도 부팅 시 주입 `.so`를 로드할 수 있다. Sony init의 "oreore env" 경로를 쓴다.

1. `/sbin/init`의 `check_mode_file()`이 **`/setting/mode/dmode`** 파일의 존재를 확인한다. 있으면 `is_oreore_env=1`.
2. `set_oreore_env()`가 **`/setting/env.txt`**를 putenv한다(`LD_PRELOAD=...` 등).
3. 이 환경은 `bootin.elf` → `im.elf`로 상속된다(LD_PRELOAD는 bootin 기동 이후에야 지워짐).

- **두 파일이 모두 필요**하다. 초기에 "env.txt가 안 먹는다"고 본 시도는 전부 `dmode` 누락 때문이었다.
- 효과: 로더/프리로드가 im.elf에 부팅 시 매핑되고 메뉴가 안정적으로 동작한다. 반면 **ptrace 주입은 im.elf의 event0 입력을 죽인다**(키가 메뉴에 안 닿고 격자는 첫 타일만 그려짐).
- `dmode`의 값에 따른 부트 모드(init의 `check_mode_file`): `0`=kernel only(드라이버 insmod 후 bootin 미실행, Sony UI 없음), `g`=gdb, `d`/`e`=DUMA/efence. 단순 존재 확인으로 oreore env가 켜진다.
- 파일 위치는 모두 `/setting`(rw FAT, NAND 백업 가능, 재부팅 복구) — `/usr` 플래시가 아니므로 **벽돌 위험 0**. 주입 `.so`도 `/setting` 아래 둔다.

## 운영 메모
- QEMU는 컨트롤 휠 **회전**을 sendkey로 보낼 수 없다(방향키만). 메뉴 탭 경계 이동처럼 휠이 필요한 검증은 실기에서만 가능.
- 자동 시작 파일 구성은 warm 재개와 무관한 지점(init이 실행될 때)에 놓이므로, 상시 warm인 카메라에서의 실제 적용 시점은 [0002](0002.%20wbi-warm-snapshot.md)의 제약과 함께 봐야 한다.
- Mods(modloader)는 UI 없이 로더 전용으로 결정되었다: im.elf 주입 시 constructor가 worker를 띄워 `/setting/a5k/mods`를 스캔하고 `mods.conf`(on|off|check)에 따라 apply/check를 수행한다. RAM-only, 가역.
