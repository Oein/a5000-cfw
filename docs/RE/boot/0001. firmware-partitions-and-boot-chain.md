# 0001. 펌웨어 패키징, 파티션, 부팅 체인

> 상태: **derived + observed**(읽기 전용 관찰, 2026-11-12).

## 1. 펌웨어 패키징
- 공식 업데이터 exe(약 202MB)는 신형 Sony 패키징이라 `fwtool unpack -f exe`가 실패한다. 내부 `.dat`(매직 `\x89UFU\r\n\x1a\n`)가 exe 오프셋 0x80242에 원본 그대로 들어 있어 잘라낸 뒤 `fwtool unpack`.
- SoC CXD90014: **DoubleAES + CRC32, 전자 서명 없음** → `fwtool pack` 재포장 가능(원본 `.dat`와 SHA-256 동일 재현 확인).
- 업데이트는 config.xml 순서대로 tar 섹션 처리. 이미지 CRC 검사는 **기록 후**(`/dev/nflashaX` 재독) 수행. `*_sum` 형식: `type,crc32(zlib),size,mode,...,path`.
- 파티션 이미지는 TPZL(LZPT) 압축: 64KB 블록 = 4KB 청크 x 16(0xF0=압축 / `0f 00 00 10`=비압축), 512B 정렬, 0 패딩. nflasha15는 압축 해제 146MB > 파티션 100MB라 재압축이 필요(인코더 미작성).
- tar 재생성(헤더 보존) 후 원본과 바이트 동일 재현 확인.

## 3. 부팅 체인
`/sbin/init` → `bootin.elf` → **`im.elf`**(메인) → `libObj.so`(ux 위젯 툴킷 + libra 리소스 DB) → `viewUnified2~8.so`(View들).
`bootin.elf` 모드: 0=kernel only, 1=Global Infra, 2=LIRO, 3=APP(기본).

## 4. 실기 환경 관찰
- 커널 `3.0.27_nl-rt106`(PREEMPT RT, 2014-10-07 빌드), 컴파일러 gcc 4.5.1(Sony CE Linux 8.2.1.1), RAM 172MB(여유 약 20MB).
- 마운트: `/`=dnflasha7(ro ext2), `/usr`=dnflasha15(ro), `/system`=dnflasha3(ro vfat), `/setting`=nflasha2(**rw vfat sync**), `/tmp`=nflasha10(**NAND vfat — 쓰기 금지**), `/log`=nflasha11. `dnflashaN` = TPZL 해제 블록 장치, `nflashaN` = raw, `/dev/nflasha` = NAND 전체(483MB).
- SD 카드는 Linux 직접 마운트 없음 — `/android/mnt/sdcard`(FuFsys FUSE), **8.3 파일명만**, **noexec**.
- Android 월드: `/usr/bin/s_start_android.sh`가 chroot `/android` 실행(CPU3, memcg 약 113M).
- 덤프 검증: NAND 전체/설정 백업의 md5가 카메라 계산값과 일치. 부트로더·nflasha1/3/5/6/7/15/16은 실시간 NAND와 일치하며 3/5/7/15/16은 1.10 펌웨어 이미지와 바이트 동일. nflasha5 꼬리에 이전 버전 WBI 잔재로 추정되는 약 200KB.
