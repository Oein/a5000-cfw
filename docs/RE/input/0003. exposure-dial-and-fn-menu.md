# 0003. 다이얼의 노출 조정 매핑과 Fn/퀵메뉴

> 상태: 모델 파라미터 ID **derived**(viewUnified2 ParamList 호출부 직접, 높음). Fn 진입 키코드는 **미확정**. 모듈 기준 주소는 viewUnified2.so / libObj.so.

## 1. 다이얼 → 노출 (P/A/S/M)

순정의 노출 적용은 전부 `CmnViewModelIfWrapper::requestModelExecute(모델블록, cmd, ParamList)`로 간다. 모델 블록 문자열: `@M00B`(카메라 본체), `@M00F`(노출/프로그램), `@M05A`(특수모드), `@M022`(듀얼렉 동영상). ParamList의 키는 모델 ADPID.

| 조정 대상 | 모드 | 구현 | 호출 | 핵심 파라미터 |
|---|---|---|---|---|
| 프로그램 시프트 | P | `WrapperProgramShift::setProgramShift` (@~0x222A00대) | `@M00F`/`@M05A`/`@M022`, cmd **0x3B** | **0x18D** = 시프트 스텝(±1), 0x18E=0 |
| 노출 보정(EV) | P/A/S | `sub_233C0C` @0x233C0C (`handleEvStep`) | `@M00F` {0x1AE,0x1B1} 전제 + `@M00B` {0x1A9, 0x1AF=2\|3, **0x1AC**=값} | **0x1AC** set, 0x1AD get(`sub_229408`), **0x286** EV 스텝(1/3=3, 1/2=2; `sub_229368`) |
| 셔터(Tv) | S/M | `sub_188254` @0x188254 | `@M00B`, cmd word_2C | **0x1A8** = 절대 값 |
| 조리개(Av) | A/M | `sub_187D38` @0x187D38 | `@M00B`, cmd word_2C+1 | **0x1A7** = 절대 값 |
| ISO | 별도 벨트 | `ACT_Iso*` | `@M00B` | 0x1AA/0x1AB 계열 관찰 |

메모:
- 셔터/조리개 세터는 **절대 값**을 받는다. 벨트 위젯이 현재 값 ± 스텝을 계산해서 호출한다. 네이티브 쪽에서 단계 이동만 필요하면 SDCom `CameraShiftShutterSpeed`(0x101A) / `CameraShiftAperture`(0x1019)가 실기 검증되어 더 안전하다([../sdcom/0003](../sdcom/0003.%20camera-parameters-and-shift-commands.md)).
- EV 스텝 크기는 `sub_229368`이 `@M00B` param 0x286으로 읽어 내부 인덱스 테이블로 매핑한다. 영속은 Backup `0x1070C7E`(스텝 설정) / `0x1070C7F`(EV 값).
- 모드 판별은 `WrapperSettingUtil::getExposureMode()`(P/A/S/M + 특수모드 25/26). M 모드는 휠이 1개라 순정은 한쪽을 휠에 배정하고, 전환은 DOWN(노출) 소프트키로 위젯 포커스를 옮긴다.
- 호출 규약(EV 예): ParamList에 모드(0x1AE)와 0x1B1=2를 `@M00F`로 실행한 뒤, 0x1A9=2, 0x1AF=스텝, 0x1AC=값을 `@M00B`로 실행.
- 소비 위젯 클래스(viewUnified2): `PAS_MenuSelectBeltWheel`, `ACT_ExposureCompensation_Classic`, `WrapperProgramShift` 등.

## 2. Fn / 퀵메뉴

- 순정 퀵메뉴는 별도 View 모듈 2개: `ViewFnMenu`(viewUnified4.so에 디컴파일 포함)와 `ViewQuickNavi`. viewUnified2의 크로스모듈 로더가 `ViewFnMenuToInstance` / `ViewQuickNaviToInstance`로 적재한다.
- 커서 이동은 공용 메뉴 유틸(`CmnZakoMenuUtil::moveCursor`, `CmnMenuTableUtil::moveCursor`, `CmnViewMenuData::cursorMoveTo`)을 재사용 — Fn 그리드도 메인 메뉴와 같은 커서 엔진이다.
- 입력: 4방향(103/108/105/106) + 다이얼(앱 모드 525/526), 센터(232)로 결정, 벨트형 항목은 다이얼/좌우로 값 증감, MENU(514)/센터 재확정/타임아웃으로 닫기. 적용은 §1과 같은 모델 실행.
- a5000에는 전용 Fn 버튼이 없다. 진입 키코드는 ViewFnMenu의 진입 이벤트 결선에 있으며 **실측 필요**. 우리 route-b 퀵바가 DOWN으로 열리는 것과 순정이 1:1 대응하지는 않는다 — 설계 자유.
- feature parity를 위해 순정 Fn 그리드 항목 집합(viewUnified4의 ViewFnMenu 테이블)을 퀵바에 그대로 담아야 한다(별도 추출 작업).

## 3. 입력 라우팅 요약

| 물리 입력 | evdev(앱 모드) | 경로 | 셔팅 뷰 액션 |
|---|---|---|---|
| 휠 CW/CCW | 525/526 | InfraDial 전용 경로 | 포커스 위젯 값 ±1 / 메뉴 커서 이동 |
| 4방향 | 103/108/105/106 | createEvent | 네비게이션, DOWN=노출·퀵 진입 |
| 센터 | 232 | createEvent | 결정 |
| MENU / 재생 | 514 / 207 | createEvent | 메뉴 토글 / 재생 진입 |
| 셔터 반 | 516+517 | createEvent | AF/AE 잠금 |
| MOVIE | 515 | createEvent | 녹화 |
| 줌 T/W | 610/611 | createEvent | 줌 |

## 4. 신뢰도

| 항목 | 신뢰도 |
|---|---|
| 노출 모델 param id (0x1A7/0x1A8/0x18D/0x1AC/0x286) | 높음 |
| ViewFnMenu 구성 | 중 (구조만) |
| Fn 오픈 키코드 | 낮음 (실측 필요) |
