# 0001. 시스템/유지보수 — 데모·클리닝·버전·인증로고·DB복원·미디어정보

> 상태: **정적 분석 확정**. 근거: `packages/data/re/ida/CautionConfig.so.c`(설정노드 루트 테이블), `viewUnified6/8.so.c`(뷰 인스턴스), `libObj.so.c`(ModelCleaning), 디바이스 실측 메뉴 `packages/data/re/static/inventory.md`·`docs/RE/menu/0002`. 실행형 뷰의 open-view Event 경로는 [menu/0003](<../menu/0003. app-launch-and-action-items.md>)와 동일.

Setup 탭 잔여 시스템 항목. 실시간 엔진 데이터면이 아니라 **값 토글 또는 뷰 실행**이다. 각 항목: control → 기구 → route-b.

---

## 1. 데모 모드 `SetupDemoMode`
- **control**: 영구 On/Off 토글 (inventory: On=0 / Off=1). 설정노드 루트 존재. 실행 측은 데모 재생 뷰 `viewDemoMoviePb`([menu/0003] 액션표).
- **기구**: 켜두면 일정 시간 무조작 시 카드 내 동영상으로 데모 재생을 띄운다(매장 전시용). "AC 어댑터 연결 권장" 경고(inventory 설명).
- **route-b**: ✅ 안전. 토글은 값 변경(휘발/영구), 재생은 뷰 실행. 벽돌 위험 0. 우리 UI에서 On/Off 제공 가능(일반 사용자껜 Off 기본).

## 2. 센서 클리닝 `SetupCleaningMode` — a5000 미노출 (핵심 발견)
- **펌웨어 존재**: 공유 펌웨어엔 클리닝 모드 자원이 컴파일돼 있다 —
  - 설정노드 루트 `cmnViewSettingNodeRootSetupCleaningMode` (`CautionConfig.so.c:15497`),
  - 엔진 오브젝트 `ModelCleaningToInstance`(`libObj.so.c:825603`, `modelCleaning.so`), 시퀀스 `ActionExeCleaningMode`→`MSGID_CLEANING_MODE_CMD`(`libObj.so.c:825728`), `SeqCleaningMode`(`libObj.so.c:2026303`).
- **디바이스 실측**: a5000 Setup 탭(inventory, menu/0002)엔 **"Cleaning Mode" 항목이 없다**. → a5000은 초음파/피에조 안티더스트 하드웨어가 없어 노드가 **게이트오프**(모델 InhFeatureCheck). (타 APS-C 상위 기종에서만 노출되는 공유자원.)
- **기구(참고)**: 트리거되면 `SeqCleaningMode`가 센서 전원/셔터를 제어해 수동 청소 자세로 전환(초음파 진동 기종에선 진동). a5000엔 진동부가 없으므로 실질 무의미.
- **route-b**: ⛔ **구현 불필요**. a5000엔 노출되지 않는 기능. 우리 커스텀 UI에 넣지 않는다(넣으려 해도 하드웨어 없음).

## 3. 버전 표시 `SetupVersion`
- **control**: 읽기전용 뷰 `ViewVersionNumberToInstance`(`viewUnified6.so.c:21482`), 설정노드 루트 `cmnViewSettingNodeRootSetupVersion`(`CautionConfig.so.c:15608`).
- **기구**: 바디 펌웨어 버전 + 장착 렌즈 버전 문자열을 조회해 표시. 읽기만 — 쓰기 없음.
- **route-b**: ✅ 안전(읽기 뷰). 순정 뷰를 open-view Event로 띄우거나, 우리 UI가 버전 문자열을 직접 읽어 표시해도 무해.

## 4. 인증 로고 `CertificationLogo`
- **control**: 읽기전용 뷰 `ViewCertificationLogoToInstance`→`view/CERTIFICATIONLOGO`(`viewUnified6.so.c:25527`), 설정노드 루트 `cmnViewSettingNodeRootCertificationLogo`(`CautionConfig.so.c:15926`).
- **기구**: 규제 인증 아이콘(FCC/CE 등) 비트맵 표시. 읽기만.
- **route-b**: ✅ 안전(읽기 뷰). 법적 고지라 커스텀 UI에서도 접근 경로 유지 권장.

## 5. 이미지 DB 복원 `MemoryCardRecoverImageDB`
- **control**: 실행 뷰 `view/MANUALREPAIR`(`ViewManualRepairToInstance` viewUnified8) / 자동 `view/AUTOREPAIR`(`ViewAutoRepairToInstance` viewUnified8). 설정노드 루트 `cmnViewSettingNodeRootMemoryCardRecoverImageDB`(`CautionConfig.so.c:15233`). 재생측 진입점은 `MANUAL_REPAIR_FOR_PLAY`(menu/0003).
- **기구**: SD의 이미지 관리 DB(AVCHD/MP4 인덱스)를 스캔해 재작성. 원본 미디어는 보존하나 장시간 걸리고 중단 위험.
- **route-b**: 🔶 실행형, **자동 실행 금지**(menu/0003 권고 동일). 사용자 명시 트리거 + 진행/중단 경고만. 벽돌 위험은 없음(SD 작업).

## 6. 미디어 정보 표시 `MemoryCardDisplayCardSpace`
- **control**: 읽기전용 뷰, 설정노드 루트 `cmnViewSettingNodeRootMemoryCardDisplayCardSpace`(`CautionConfig.so.c:15191`).
- **기구**: SD 잔여 용량/촬영가능수 표시. 읽기만.
- **route-b**: ✅ 안전(읽기). 우리 OSD/메뉴가 잔여수를 직접 표시해도 됨(엔진 미디어 상태 read).

## 8. route-b 종합 판정
- 잔여 시스템 항목은 전부 **벽돌 위험 0**: 읽기뷰(버전/인증/미디어정보)·안전토글(데모)·SD작업(DB복원)·순정뷰실행(나머지). route-b는 [menu/0003]의 open-view Event로 순정 뷰를 띄우거나 값만 토글.
- **센서 클리닝은 a5000 비대상** — 구현 제외.
- 영구 토글(데모/PAL·NTSC 등)은 backup propId 경로를 쓸 때 [backup] Tier 확인 후 **메뉴-쓰기 집합(subsystem 0x107)** 내에서만. 아니면 순정 뷰 경유가 안전.

## device-only / 미확정
1. `SetupDemoMode`/PAL·NTSC 등 영구 토글의 Backup propId 인덱스 — backup/0002 측정표 대조(실기 덤프).
2. `SetupVersion` 버전 문자열 소스(system model query) 상세 — 읽기전용이라 영향 없음.
3. 센서 클리닝 게이트 분기(InhFeatureCheck 모델 플래그) — a5000 미노출만 확정, 분기 상세 불필요.
