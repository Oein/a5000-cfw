# 0004. SDCom 이벤트 구독과 수신 분기

> 상태: **derived**. 이벤트 번호 왕복(등록 id ↔ 수신 id)은 실기 미확인.

## 구독
- `RegisterEvent` 0x0001/0x0002, `RegisterEventGroup` 0x000B/0x000C.
- RegisterEvent 파라미터: **id 2 / IntArray = 구독할 이벤트 id 목록**(필수, 없으면 에러 2), **id 84 / Int = 0/1 플래그**. RegisterEventGroup은 추가로 id 86.
- 등록하는 id는 엔진 내부 이벤트 번호(81개 목록: CameraEvent*/MovieEvent*/Display*/Media*/Audio*; 예: ShutterEventList = 0x1404, 0xF003, 종결자 0xFFFFFFFF; FocusDone = 0x1301, 0x2001; AeLock=0x12BB; DriveMode=0x1333). 수신할 때는 SDCom msgId(0x2xxx)로 온다.
- 클라이언트 이벤트 디코딩은 리스너 오버라이드(`SDComIPCListener::onEventReceived`)에서 한다. 베이스 구현은 free만 하는 stub.

## 수신 분기 (libcamera `onEventReceived_thread`, 35개)
| 수신 msgId | 핸들러 의미 |
|---|---|
| 0x2007 / 0x2008 | 셔터 / 조리개 변경 |
| 0x200A, 0x200C~0x200F | 초점 완료(FocusDone) |
| 0x2001, 0x2002, 0x2004 | STD 초점 이벤트 |
| 0x2011, 0x2012, 0x2014 | 커스텀 WB 캡처 |
| 0x2015, 0x2026, 0x202C~0x2030 | 적정 노출 레벨 |
| 0x2017~0x201A | 프로그램 라인 오버 / 측광 범위 |
| 0x201B / 0x201F | 기록 미디어 |
| 0x2023 / 0x2025 | 설정 변경 |
| 0x2028 / 0x2029 | 파워 줌 |
| 0x100D, 0x2000, 0x0121 | 카메라 시퀀스 시작 |

⚠️ 일부 그룹 경계(분기 비교 경계)는 부정확할 수 있다 — 실기 RegisterEvent 후 수신 id 캡처로 보정 필요.

## 송신 측 참고
`SDComServer::sendEvent` 호출처 추적에서 Display/Record/MovieConnectMedia 등 `CommandProcessor*::sendEventMessage`가 이벤트 발행의 주체로 확인된다(DisplayImage는 인자 0x71, RecordImage는 0x72를 사용).
