# 0003. 카메라 파라미터 조회와 Shift 명령

> 상태: **observed** (CameraGetParameters, ShiftShutterSpeed 실기 성공). 이름표는 `CommandProcessorCameraSetParameters`의 키 변환표(`s_ADParamKeyConvTable`, 항목 20B: id, 내부 키, 타입, idx, 값표 심볼)에서 도출 — 원본 TSV는 `packages/data/re/scalar/camera_params.tsv`.

## 1. CameraGetParameters (0x1002)
- 응답 116개 파라미터. 카메라가 열려 있으면 어떤 클라이언트든 조회 가능.
- 기준 값(바디 상태: M 모드, AF-S, 1/640, f/1.8, EV0, ISO200)으로 검증한 id:

| id | 이름 | 실측 값 |
|---|---|---|
| 256 | stillFormatSize | [5456,3064] |
| 257 | stillFormatType | 4 |
| 259 | stillFormatQuality | 50 |
| 260 / 279 | wbMode / wbMode2 | 0 / 1 |
| 261 | colorModeType | 0 |
| **263** | **exposureMode** | **19 (M)** |
| 264 | strobeModeType | 2 |
| **265** | **focusMode** | **0 (AF-S)** |
| 266 | exposureBias | 0 |
| **267** | 조리개 | **180 (= f/1.8 x100)** |
| **268** | 셔터 | **[1,640] (= 1/640)** |
| **269** | isoGain | 200 |
| 270 | meterMode | 0 |
| 271 | afAreaModeAlt | 0 |
| 272/273 | droLevel/droLevel2 | 1/1 |
| 274/275 | hdrLevel/hdrLevel2 | 0/1 |
| 277 | redEyeReduction | 2 |
| 280 | wbColorTemperature | 4000 |

- 지원 값 조회는 CameraGetSupportedParameters(0x100A, param 118).
- SDCom 설정 param id 축은 **256~388**. 설정을 바꾸는 대부분은 `CameraSetParameters`(0x1003, IntArray)로 간다.

## 2. 조리개/셔터는 값표가 없는 Shift 방식
SetParameters 표에 조리개/셔터 값표가 없어 **Shift 명령**으로 단계 이동한다.
- `CameraShiftShutterSpeed` 0x101A, `CameraShiftAperture` 0x1019, `CameraShiftProgramLine` 0x102D — IntParam **id 5 = 단계 수**(−63..63 클램프).
- 방향: +1 = 더 빠른 셔터(1/640 → 1/800). 결과 코드 0.
- **반영은 비동기**: 명령 직후 GetParameters는 이전 값을 돌려주고 약 2초 뒤 반영된다(앱은 50ms 폴링 `settledState()`로 대기).
- 실측(화면 확인): `0x101A id5=+1` 대기 2s → `[1,800]`, `id5=-1` → `[1,640]`.
- 다른 SDCom 클라이언트(앱)가 동시에 돌아도 충돌 없음(앱은 요청 시에만 설정 변경, 주기 재적용 없음).

## 3. Superior Auto
"프리미엄 자동(Superior Auto)"만 SDCom 경로가 있다 — `s_exposureMode` 값표에 포함 → CameraSetParameters 0x1003의 param 263(exposureMode) enum 중 하나. 정확한 수치는 값표가 런타임 .bss 표라 정적으로는 안 나온다(현재 M=19). 자동모드 설정 노드 35: Intelligent=0 / Superior=1. 메뉴 토글 + 라이브 덤프로 확정할 것.

## 4. 번호 네임스페이스 구분 (자주 혼동됨)

| 네임스페이스 | 예 | 용도 |
|---|---|---|
| 설정-노드 ID (settings tree의 `13=`) | AF 보조광 16, 자동 모드 35, 피킹 54/55, 제브라 194, 비행기 181 | UI/메뉴 전용. **SDCom addParam에 쓰면 안 됨** |
| SDCom param ID | 256~388 (exposureMode 263 등) | `CameraSetParameters` |
| Backup propId | `(subsystem<<16) \| index`, 0x107xxxx | 영속 저장 ([../backup/](../backup/README.md)) |

따라서 피킹·제브라·AF 보조광은 SDCom 0x1003으로 **set 불가**(키 자체가 camera 표에 없음). 엔진 내부 PARAMID와 Backup prop 경로로만 제어한다.

## 5. 촬영/라이브뷰 명령 흐름 (derived)
- 라이브뷰 켜기: `OpenCamera` 0x1000 → `CameraStartPreview` 0x1004 (0x0127이 아님). 영상 사각형은 `GetVideoLayout` 0x0604, 변경 알림은 `StartYUVAreaGet` 0x0603(픽셀 fetch 아님).
- 촬영: AutoFocus 0x1006 → TakePicture 0x1008 → StopTakePicture 0x1027, 셀프타이머 0x1020/0x1021.
- 동영상: StartMovieRecording 0x3002 / Stop 0x3003.
- 줌: StartZoom 0x102E / StopZoom 0x102F / SetDigitalZoom 0x1030, 초점 확대 0x1032/0x1033/0x1036.
- 라이브뷰 영상은 하드웨어 VDF 영상 평면에 엔진이 직접 그리며 OSD가 그 위에 합성된다(Z순서 구조적으로 해결). 연속 프레임을 클라이언트로 pull할 수 있는지(`CamseqGetPreviewFrame`)는 미확정. 자세한 합성은 display 카테고리.
