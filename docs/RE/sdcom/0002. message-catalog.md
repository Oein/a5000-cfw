# 0002. SDCom 메시지 카탈로그

> 상태: **derived**. 146개 메시지 id(카테고리 팩토리 dispatch)와 147개 명령 처리기(요청 파라미터)가 `libScalarDaemon`의 CommandProcessor 집합과 1:1로 맞는다 — 정적으로 **사실상 완전**. 일부 id는 실기 시험 완료(0x1002, 0x101A, 0x000D, 0x0009).
> 원본 표(TSV)는 `packages/data/re/scalar/`에 보관. 아래는 패밀리별 요약.

## 설계 갭 (SDCom에 없는 것)
- **정지영상 재생**: 재생 명령셋이 없다(FactoryPlayer 0x0070은 루트일 뿐, 유일한 플레이어는 HDMI/DLNA용 OneTouchPlay). → SD의 DCIM JPEG/ARW **직접 디코드**.
- **이미지 DB 복원**: SDCom 메시지 없음 → in-process 모델 전용([../menu/0003 §5](../menu/0003.%20app-launch-and-action-items.md)).
- **UI 설정류**: 언어·시계·포맷·Wi-Fi는 SDCom이 아니라 Android Settings framework / Backup.bin.
