# 0001. SDCom 전송·연결 프로토콜과 ScalarDaemon 수명주기

> 상태: 연결/요청 형식 **observed**(실기 성공), 수명주기 상태머신 **derived**(libScalarDaemon 정적). 라이브러리: `/usr/lib/libsdcom.so`(glibc ARM, 직접 링크 가능).

## 1. 전송
- OSAL UIPC 커널 메시지 큐(`libosal_uipc.so`: `osal_dynamic_id`, `osal_snd_msg`, `osal_rcv_msg_tmo`) 위의 요청/응답 IPC.
- 데몬 큐 id: **0x1540432**. 클라이언트는 **자신의 수신 큐 id로 구분**되므로 같은 컴포넌트 id가 중복되어도 기존 앱 연결에 영향이 없다.

## 2. 연결(`SDComIPC::connect`)
1. 상태가 -1(초기)이어야 한다 → 수신 큐 할당 → 수신 스레드 시작
2. 메시지 id 1 생성(`createNewMessage`) + `SDComMsgIntParam`(param id 2 = 클라이언트 type)
3. 송신 후 5초 대기, 응답 IntParam(id 1) = 결과 코드(0=성공)
4. 상태 전이: -1 → 2(연결 중) → 3(연결됨)
- type 값 예: 카메라 HAL=2, 설정=0xC (Android 클라이언트가 쓰는 값).
- 데몬은 상태 5 또는 9(Scalar 활성)에서만 연결을 수락한다(그 외는 에러 5).

## 3. 요청 형식
`createNewTransactionId` → `createNewMessage(0x1540432, 5, tx)` → `setMessageId(cmd)` → `addParam`(IntParam 등) → `sendSync(msg, &reply, 5s)`. 응답의 param id 1(Int) = 결과 코드(0=성공). 응답 파라미터 열거는 `getFirstParam/getNextParam(msg, true)`(복사본 반환, 호출자가 delete). 타입 코드: 1=Int, 2=Binary, 3=String, 5=IntArray, 6=StringArray.

## 4. 데몬 수명주기 (D2A / A2D)

상태 워드(`*(this+24)`):

| 상태 | 의미 |
|---|---|
| 1 | init |
| 2 | finalizing |
| 3, 4 | initialized (SDCom 닫힘) |
| 6 | D2A 진행(`onD2ARequested`) |
| **5** | **Scalar 활성(D2A 완료, `onD2ACompleted`)** |
| 7 | A2D 진행 |
| 8 | A2D 클라이언트 끊김 대기 |
| 9 | (엔진이 설정, libScalarDaemon에 setter 없음) 연결/명령 허용 |

- 명령 dispatch는 상태 5/8/9에서만(비트마스크 0x320).
- D2A: `onD2ARequested` → setState(6) → `CommandProcessorSwitchD2A::AsyncProcessor::execute` → `ScalarDaemon::openSDCom()`(SDComServer 생성) → 설정 보존 → `onD2ACompleted` → setState(5) → 연결 수락.
- A2D: setState(8) → 클라이언트 끊김을 **10초** 기다림(타임아웃 시 abort) → setState(7) → 설정 복원 → `onA2DCompleted` → setState(4) → closeSDCom. 따라서 A2D 브로드캐스트를 막으면 안 되고 장기 세션은 시그널에서 반드시 disconnect.
- **`onD2ARequested` 호출자는 scalar 바이너리 어디에도 없다.** im.elf의 Diadem View/모드 레이어(엔진 측)가 호출한다 — 카메라가 앱 모드에 진입할 때 엔진이 트리거. sdprobe가 ILCE Remote 전경일 때만 접속에 성공한 이유가 이것(state 5). 0xF000 `SwitchD2A`를 클라이언트가 다시 쏘는 대안은 닭-달걀(접속하려면 이미 5/9여야 함).
- `ShowState` 0xF002는 디버그 덤프.

## 5. 실기 확인된 호출
- connect=0, `GetBodyFirmwareVersion`(0x000D) → param id 97 = 0x1000A(= 펌웨어 1.10), `GetSystemState`(0x0009) → id 69 = 2, disconnect=0.
- 소유권 검사 없음: 카메라가 열려 있으면(전역 ParameterEntry 상태 1/2) 어느 클라이언트든 조회 가능 — 앱 세션을 유지한 채 별도 프로세스에서 읽을 수 있다.

## 6. 열린 항목
- standalone(비-Android) 프로세스가 앱 슬롯을 점유했을 때 엔진이 여전히 D2A를 발동하는지(트랙 B 임계 경로 1순위)
- 상태 5 유지 조건, 상태 9 setter
- 이벤트 id 왕복([0004](0004.%20event-subscription-and-dispatch.md))
