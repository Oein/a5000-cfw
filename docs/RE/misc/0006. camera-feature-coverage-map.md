## Gap 조사 웨이브 (에이전트 투입 계획)
동시성·IDA 단일 라이선스 때문에 웨이브로 투입한다. 각 에이전트는 SDCom 카탈로그([sdcom 0002/0003](../sdcom/README.md))·에뮬·로컬/pre-decomp 디컴파일 캐시를 1차 도구로 쓰고, 동작 의미(엔진이 실제로 뭘 하는가)와 route-b 구동 가능성을 답한다.

- **웨이브 1 (진행):** 포커스 시스템(B), 캡처·룩·화질(C+D), 동영상·손떨림·줌(F+G+I)
- **웨이브 2 (웨이브1 종료 후):** 장면·자동지능(E), 연결 흐름(K, network 에이전트 종료 후), 표시 보조(L) + 측광(A) + 플래시(H)

결과는 카테고리별 신규 문서(`docs/RE/focus/`, `shooting/`, `movie/`, `scene/`, `connectivity/`, `display` 보강 등)로 쌓고 이 맵을 갱신한다.
