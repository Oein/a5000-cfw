## Gap 조사 웨이브 (에이전트 투입 계획)
동시성·IDA 단일 라이선스 때문에 웨이브로 투입한다. 각 에이전트는 SDCom 카탈로그([sdcom 0002/0003](../sdcom/README.md))·에뮬·로컬/pre-decomp 디컴파일 캐시를 1차 도구로 쓰고, 동작 의미(엔진이 실제로 뭘 하는가)와 route-b 구동 가능성을 답한다.

동시성은 **gap-RE 에이전트 2개 이하**로 유지(사용자 2026-11-20 지시). 슬롯이 비는 대로 큐에서 2개를 채운다.

- **웨이브 1 (완료):** 포커스(B)→`focus/`, 캡처·룩·화질(C+D)→`shooting/`, 동영상·손떨림·줌(F+G+I)→`movie/`. + 선행 완료: RAM→`memory/`, 재생/RAW(J)→`playback/`, AF-WiFi→`network/`.
- **웨이브 2 (진행):** 장면·자동지능(E)→`scene/`, 연결 흐름(K)→`connectivity/`.
- **웨이브 3 (진행):** 측광(A) + 표시 보조(L: 히스토그램/수평계/그리드/DISP), 그리고 플래시(H) + 시스템 유지보수(M 잔여).
