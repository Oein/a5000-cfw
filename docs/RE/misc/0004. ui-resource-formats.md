# 0004. UI 리소스 포맷 (uxc / xdb)

> 상태: 문자열 **해독 완료**, 이미지 **부분**, 레이아웃 **미해독**. (메뉴 재배치에는 불필요하며 아이콘/레이아웃 수정용.)

| 파일 | 상태 | 포맷 |
|---|---|---|
| `string_<lang>.uxc` (`uxc\x07`) | 해독 완료 | u16 인덱스 + `[u32 id][UTF-8\0][4정렬]`. id `0x1E04xxxx` ↔ 코드 resid `0x0204xxxx`. 약 4,179개(가이드 문자열 3,293) |
| `global.xdb` (`uxa\x07`) | 해독 | 모듈 번호 → 리소스 파일명 인덱스 |
| `image_*.uxc` (`uxd\x07`) | 부분 | 레코드 20B `[id 0x1aXXXXXX][fmt 0xe0000000][w u16][h u16][csize][off]`. 픽셀 압축(니블 RLE 추정) 미해독. `image_cmn_169`는 다중 섹션 |
| `view*.uxc`, `master_*.uxc`, `LayoutMaster_Menu.uxc` | 미해독 | 위젯 트리 직렬화(속성명 해시 u32 + 타입 + 값). 로더는 libObj의 이름 없는 `libra` 내부 함수 |

- uxc 헤더 `+0xA u16` = 모듈 번호(global.xdb 인덱스): viewGlobalMenu=0x8E, viewSettingMenu=0x4C, string=0x27 등.
- 탭바 위젯 id 0xA056F604(PAS_MenuListTab)는 6탭이 코드에 고정되어 있음 → [menu 0001 §7](../menu/0001.%20stock-menu-node-tree-structure.md).
- 폰트(.ltt)와 아이콘(uxd 픽셀 압축)은 미해독. 자체 UI 자원을 쓰면 불필요.
- 추출된 문자열 표(TSV)와 이미지 인덱스는 `packages/data/re/`(비공개; Sony 자원 파생).
