# 0003. 제브라 라이브 적용 경로

> 상태: **derived**(정적, 코드 증거 기반). 결론: **제브라는 SDCom 클라이언트 메시지로 set할 수 없다.**

## 적용 체인 (엔진 내부)
1. MWF ObjMsg `MSGID_SET_ZEBRA_CMD`(0x200C)
2. `ObjRenderer::ExecCommandSetZebra`(libObj `sub_1FAC7C`)
3. OSAL 메시지 **0x59000E**(`MSG_ID_VDF_SRVC_SET_ZEBRA`)로 VDF 서비스에 16바이트 페이로드 송신

페이로드(16B): +8 sel, +9 on/off, +A gray(PARAMID 0x290063), +B 상한 IRE(IRE+5), +C 하한 IRE(IRE−5). IRE 매핑: gray 0→70 … 6→100, **7→104(100+)**.

## SDCom에 없는 이유
- SDCom의 `8204`/0x200C는 **이벤트 구독 id**(제브라 변경 알림)이지 set이 아니다.
- 메시지 id 표, 요청 파라미터 표에 제브라 항목 없음. `CameraSetParameters`(0x1003)의 키 문자열에도 zebra 없음.

## 현실적인 적용 경로
| 경로 | 가능 여부 |
|---|---|
| (a) 직접 SDCom | 불가 |
| (b) Backup prop 0x010701B8/B9 기록 | 영속은 되지만 **재부팅 후 적용** |
| (c) 네이티브 메뉴를 입력 주입으로 조작 | 앱이 할 수 있는 유일한 in-firmware 즉시 경로 |
| (d) OSAL 0x59000E 직접 주입 | 엔진 컨텍스트 필요(SDCom 미노출) — route-b in-proc에서 가능성 |

## 미해결
- `PARAMID_ZEBRA_*` 숫자값(난독화), ConvertCid/CmdMid(0, 0x11)의 구체 값.

같은 이유로 **피킹/AF 보조광도 SDCom set 불가**이며 엔진 내부 PARAMID + Backup prop 전용이다([../sdcom/0003 §4](../sdcom/0003.%20camera-parameters-and-shift-commands.md)).
