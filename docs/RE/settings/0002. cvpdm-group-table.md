# 0002. cvpdm-group-table

상태: 읽기/쓰기 경로 정적 확정, expcomp(20)은 뷰 독립 읽기 실기 증명. 나머지는 정적.

## 경로 (Path B / "W1 group")
CmnViewProcessDataMgr 그룹 경로.
- 읽기: vtable[3]. 쓰기: vtable[14].
- `dword_37AFF8[group]` = 내부 id. 그룹별 Element가 매니저의 저장된 뷰(`this+4`)를 가진다.
- engine.h 오프셋: CVPDM_RD_VOFF=12, CVPDM_WR_VOFF=56 (vtable 슬롯 3/14 x4).
- 뷰 독립: 현재 뷰 라우팅에 의존하지 않아 라이브뷰 off에서도 읽힌다(camera/0002의 getModelInfo 게이트와 대비).
