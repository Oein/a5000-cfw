# 0001. monitor-brightness-apply

상태: 적용 경로 정적 확정. 현재 구현(`brightness`)은 앱 로컬(AM_LOCAL)이라 엔진에 반영되지 않는 버그 상태. 수정안 제시(미적용).

## 순정 항목
SetupLCDBrightness(모니터 밝기). settings_tree의 `13=120` -> CmnViewProcessDataMgr **그룹 eventId 120**.
옵션 raw: Auto 0 / Manual 1 / Sunny 2 / Normal 3 / Bright 4.

## 적용 경로
- Element: _ZTV@0x433a48, 내부 id `dword_37AFF8[120]` = 0x40.
- 쓰기: `cvpdmGroupWrite(120, raw)` = vtable[14] (`sub_1943A2`).
- 읽기(되읽기): vtable[3] (`sub_1944EE`).

## 안전성 (벽돌 위험 0)
엔진 그룹 쓰기(RAM, 가역)이며 Backup/flash raw 쓰기가 아니다. 이미 연결된 측광(22), 화질(2)과 동급.

## 수정안
현재 `brightness`를 AM_LOCAL에서 kGroupApply 행(group 120)으로 변경. 주의: uicore 옵션 목록은 4개, raw 값은 5개이므로 되읽기(read-back) 가드로 불일치 시 롤백/무시한다.

## 관련
settings/0002 (그룹 테이블).
