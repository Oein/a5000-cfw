## 한 줄 결론
a5000(CXD90014)은 **전자 서명이 없다** — 보호는 공개 키 대칭 AES + CRC/체크섬(위조 가능)뿐. 따라서 "서명 장벽"은 없으나, **권장 영속화는 플래시 무수정 `/setting` LD_PRELOAD(벽돌 위험 0)**이고, 플래시를 실제 고칠 때의 진짜 블로커는 서명이 아니라 **WBI 정합성 + 복구 불변식**이다.
