# 0004. 순정 메뉴 항목 → 구현 경로 맵

> 상태: 트랙 A 앱 기준 구현 현황(2026-11-13 최신화) + 경로 분류. **북극성**: 순정 전 항목 100% 보존(기능 제거 아님). 트랙 A 앱은 빌드·API10 통과 후 실기 검증 완료.

## 1. 경로 유형

| 유형 | 경로 | 비고 |
|---|---|---|
| ENUM/BOOL/RANGE | 표준 `Camera.Parameters` — 엔진이 적용+영속 | propId 매핑 불필요 |
| PREF | 앱 동작(SharedPreferences)/Android API | |
| ACTION | 갤러리/시스템 액션(일부 EXPERIMENTAL 게이트) | |
| EXP | `CameraEx.ParametersModifier`(네이티브 파라미터), 게이트 기본 OFF | 1개씩 켜서 확인 |
| INFO | 표시 전용 또는 "미지원" 자리표시 | |

## 2. 구현 분류 (약 95개 완료 / 약 27개 테스트 후 가능)

### 이미 구현(표준 경로)
- **촬영 탭**: 이미지 크기/종횡비/화질, 드라이브·셀프타이머·연사·브라케팅, 플래시, 초점 모드·AF 모드·초점 영역, 노출 보정·ISO·측광, DRO/HDR, 자동 저속 셔터, AE 잠금, 고감도 NR, 화이트 밸런스·색온도·WB 미세조정, 크리에이티브 스타일(+대비/채도/선명), 사진 효과(+세부), 색 공간, 얼굴/미소 검출, 소프트 스킨, 촬영 팁 표시
- **사용자 설정 탭**: Live View 표시, 눈금, DISP, 노출 가이드, 자동 리뷰, 초점 확대 시간, 프리뷰 확대, 줌 설정, 사용자 정의 키, MOVIE 버튼, 렌즈 보정, 흔들림 방지, 리모컨
- **무선 탭(설정성)**: 비행기 모드·장치 이름(게이트), MAC 표시
- **애플리케이션 탭**: 앱 목록, 소개
- **재생 탭 전체**: 삭제, 보기, 인덱스, 슬라이드쇼, 확대, 회전, 보호, 인쇄 지정, 표시 회전
- **설정 탭(다수)**: 밝기, 음량, 오디오 신호, 타일 메뉴, 데모, 포맷/DB 복원(게이트), 정보 읽기(장수, 미디어, 삭제 확인, 날짜/시간, 펌웨어/모델/UI 버전, 인증 로고)

### 테스트하면 넣을 수 있음
- **EXP 14**: 바람소리 감소, Lock-on AF, SteadyShot, AEL, 절전 시작 시간, HDR 레벨 등(상위 기종용 항목은 [0002](0002.%20stock-menu-inventory-device-verified.md)의 정정으로 제거)
- **네이티브 전용 약 13**: 제브라, 피킹 레벨/색, AF 보조광, PAL/NTSC, 언어, 지역, HDMI 해상도/제어, USB 연결/LUN, REC 폴더 선택/새 폴더/폴더명. 설정 노드 ID는 제브라 194, 피킹 54/55, AF 보조광 16(**SDCom param ID가 아니라 메뉴 노드 ID**).

## 3. 네이티브 전용의 현재 상태
- 피킹 레벨/색, AF 보조광, 제브라 enable/레벨, 오디오 신호는 Backup propId가 실측 확정됨 → [../backup/0002](../backup/0002.%20propid-mapping-measured.md).
- 제브라 라이브 적용은 SDCom 불가(VDF 내부) → [../backup/0003](../backup/0003.%20zebra-live-apply-path.md).
- PAL/언어/지역은 Tier B(민감). 값 범위(enum)는 settings 카테고리의 옵션 트리에 이미 있어 기기에서 훑을 필요가 없다.

## 4. UI 설계 결정 (참고)
- 네이티브 UI 메인 메뉴는 **캐스케이드/밀러 3열 리스트**이고 타일 메뉴는 쓰지 않는다. 모든 항목·기능은 유지하고 표현만 바꾼다.
- 순정 7번째 "Mods" 탭/항목 주입은 불가([0001 §7](0001.%20stock-menu-node-tree-structure.md)) — Mods는 UI 없는 로더로 결정.
