# 0002. 순정 메뉴 실측 인벤토리 (a5000 실기 기준)

> 상태: **observed**(실기 메뉴 화면 20장 전수 기록, 2026-11-13). 디컴파일 설정 트리는 상위 기종 공용 카탈로그라 a5000에 없는 항목도 포함 — **이 문서가 "a5000에 실제 있는 설정"의 기준**이다.

6탭 / 20페이지 / 약 106항목. 굵게 표시한 항목은 네이티브 전용(엔진 내부 상태 또는 Backup 경로가 필요) 후보다.

## 탭1 촬영 (6p)
1. 촬영 모드 · 이미지 크기 · 종횡비 · 화질(RAW+JPEG) · 파노라마 크기 · 파노라마 방향
2. 파일 형식 · 녹화 설정 · 드라이브 모드 · 플래시 모드 · 플래시 보정 · 적목 현상 감소
3. 초점 모드 · 초점 영역 · **AF 보조광** · 노출 보정 · ISO · 측광 모드
4. 화이트 밸런스 · DRO/자동 HDR · 마이 스타일(크리에이티브 스타일) · 사진 효과 · 초점 확대
5. 고감도 ISO NR · **Lock-on AF** · 미소/얼굴 인식 · 소프트 스킨 효과 · **자동 프레이밍**
6. **SteadyShot** · 색 공간(실기 값 AdobeRGB) · 자동 저속 셔터 · 오디오 녹음 · **바람 소리 감소** · 촬영 팁 목록

## 탭2 커스텀 (4p)
1. **제브라 패턴** · MF 도우미 · 초점 확대 시간 · 눈금 표시 · 자동 리뷰 · DISP 버튼
2. **피킹 레벨** · **피킹 색상** · 노출 설정 가이드 · Live View 표시 · 사전-AF
3. 줌 설정 · 렌즈 없이 촬영 · **반셔터 시 AEL** · 셀프카메라/타이머 · 자동 이미지 추출 · 얼굴 등록
4. 사용자 정의 키 설정 · MOVIE 버튼 · AF 미세 조정 · 렌즈 보정

## 탭3 무선 (2p)
1. 스마트폰으로 보내기 · 컴퓨터로 보내기 · TV에서 보기 · 원터치(NFC) · 비행기 모드 · WPS 푸시
2. 액세스 지점 설정 · 장치 이름 편집 · MAC 주소 표시 · SSID/PW 재설정 · 네트워크 설정 리셋

## 탭4 애플리케이션 (1p)
애플리케이션 목록 · 소개

## 탭5 재생 (2p)
1. 삭제 · 보기 모드 · 인덱스 표시 · 표시 회전 · 슬라이드쇼 · 회전
2. 확대 · 4K 정지 이미지 재생 · 보호 · 인쇄 지정

## 탭6 설정 (5p)
1. 모니터 밝기 · 음량 설정 · 오디오 신호 · 타일 메뉴 · 삭제 확인
2. 절전 시작 시간 · 데모 모드 · HDMI 해상도 · HDMI 제어 · USB 연결
3. USB LUN 설정 · 언어 · 날짜/시간 설정 · 지역 설정
4. 포맷 · 파일 번호 · REC 폴더 선택 · 새 폴더 · 폴더명 · 이미지 DB 복원
5. 미디어 정보 표시 · 버전 · 설정 리셋

## 카탈로그 정정 (이 실측 기준)
- **a5000에 실제로 있어 유지**: SteadyShot, 바람소리 감소, Lock-on AF, 반셔터 AEL, 절전 시작 시간(+제브라/피킹/AF 보조광/DRO·HDR은 확정).
- **a5000에 없어 제거**(상위 기종용 CameraEx 메서드): APS-C/Super35, ND 필터, 시네마톤, 모션샷, 무음 촬영, RAW 압축 형식 선택(a5000 RAW는 항상 압축), 동영상 SteadyShot 별도 항목(일반 SteadyShot에 포함), 촬영결과 미리보기(Live View 표시로 충분).
- **미지원으로 잘못 분류했으나 실제 존재, 구현 대상**: 자동 프레이밍(촬영 p5), 셀프카메라/타이머(커스텀 p3), 자동 이미지 추출(커스텀 p3).
