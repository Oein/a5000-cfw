# 0001. video-playback — 순정 동영상 재생 파이프라인

상태: 정적 분석 확정(로컬 Hex-Rays 캐시 `packages/data/re/ida/` + 에뮬 RE 문서 교차). SA DSP 디코드 실데이터·정확한 코덱 타이밍은 디바이스/실데이터 확인 필요(명시함).

주소 표기: `libObj+X` = `/usr/lib/libObj.so` IDA 오프셋(base 0). av-cam는 절대 VA(load 0x43541000, Thumb). VPH 레지스터는 PA.

---

## 0. 요약

| 질문 | 답 |
|---|---|
| 컨테이너/코덱 | **AVCHD(.MTS/.M2TS, H.264 + Dolby/AC-3 또는 LPCM)** 와 **MP4(MPEG-4 AVC/H.264 + AAC)**. a5000 녹화 포맷은 `cmnViewSettingNodeMovieFileFormatAVCHD_*`(60i/60p·50i/50p·FH/FX/FZ) 설정 노드로 확인. XAVC-S는 a5000 비대상(단 `MprCtrl::GetMediaTransferRateXAVC` 심볼은 공유 라이브러리에 존재). |

## 1. 진입과 모드

- 재생 뷰 = funcMode **21**(camera/0001). 정지화상 단일 뷰 `ViewSinglePbToInstance`, 인덱스(그리드) `ViewIndexPbToInstance` (둘 다 `viewUnified2.so`). 동영상 재생은 단일 뷰의 동영상 분기.
- PLAY 진입은 라이브뷰 정지(EE_STOP)를 먼저 요구한다(모델트리 전환, camera/0002·sdcom 참조). 에뮬에서 이 핸드셰이크가 과거 블랙스크린 원인이었고 null-SA 모델로 `EE_STOP_CMP`가 완료된다(에뮬 `RE_SD_MEDIA_SERVICE.md` §10, `RE_PLAYBACK_SWITCH.md`).

## 2. 재생 체인(순정, 엔진)

```
UI(ViewSinglePb, 동영상 분기)
  → MprIf::PlayMovie(mediaId, EntryId, RSMPoint*, PlayMovieCtrl*)      libObj+0x31100
  → ObjEffect: SequenceFactoryComponentMoviePlay                       (ObjEffect)
  → InfraMovieDecoder (InfDecoder): Create → SeqDecStart → (ChgSpeed)   libObj InfraMovieDecoder*
  → SA DSP ZIMA AVC 디코더 (av-cam, sa_avcd_*_zma.bin)                   (av-cam)
  → 디코드 YUV → VDF YUV 핀 → VPH ch51
오디오: SA 오디오 코덱(ac3dec/aaclcdec/lpcmdec) + LPS
```

- **컨테이너/코덱 식별**: `PAS_Index::isContentTypeAVCHD`(인덱스 분류), `MprCtrl::GetMediaTransferRateXAVC`. 녹화 설정 노드가 AVCHD 60i/60p·50i/50p·FH/FX/FZ 비트레이트를 정의 → 재생 컨테이너도 AVCHD(TS)와 MP4.
- **디코드**: `InfraMovieDecoder`가 `codecID`로 디코더를 선택(`[InfDecoder][*TEST*] MovieDecoderSeqDecChgSpeed codecID : %x`). 실제 AVC 디코드 연산은 SA DSP ZIMA 프로그램에서 수행(에뮬 `RE_SA_DSP.md` §6: ZIMA = `sa_avce/avcd_*_zma.bin`, null-SA에선 실데이터 없음 → 빈/정지 프레임). 즉 **디코드는 Sony 전용 SA 펌웨어** — Linux im.elf는 제어/시퀀싱만.
- **프레임 → 평면**: 디코드 YUV는 라이브뷰와 같은 VDF YUV 핀을 통해 **VPH ch51 (panel YUV)** 로 scanout(에뮬 `RE_DISPLAY_SCANOUT.md` §0·§표: ch51 = "panel YUV (live view / playback image)"). GPU PPF/별도 비디오 평면 아님. Y/C 주소는 VDF 핀이 공급, Linux는 0xF344xxxx VPH를 건드리지 않음.

## 3. 트랜스포트 / seek / pause 제어 표면

- `MprIf::PlayMovie` / `MprIf::CancelPlayMovie`(libObj+0x31610).
- 재생속도/방향(배속·역재생·일시정지) = `InfraMovieDecoderSeqDecChgSpeed`.
- UI 컨트롤패널: `LG_master_browser` 레이아웃 `CMN_M_PLAY_MOVIEPLAYBACK_CONTROLPANEL_7ITEMS`(재생/정지/빨리감기 등 7버튼), 재생중 오버레이 `CMN_M_PLAY_MOVIEPLAYING`, 네트워크(리모트) 변형 `M_LAYOUT_43_PLAY_MOVIEPLAYBACK_CONTROLPANEL_6ITEMS`.
- 타임코드 표시: `ObjRenderer SequenceSetTimeCodeCmd` / `ExecCommandVdfSetTimeCode`.
- 제어 통로는 엔진 메시지(ObjEffect/ObjRenderer → MprIf → libmpr → SA). SDCom은 상위 토글 수준이며, 프레임 단위 트랜스포트는 MprIf 경로.

## 4. 오디오 경로

- 디코드: SA 오디오 코덱 `sa_ac3dec`(AVCHD Dolby), `sa_aaclcdec`(MP4 AAC), `sa_bd_lpcmdec`(LPCM). LPS(`LPS GetMailBox 438B48D8`) 메일박스 콜백 의존(에뮬 `RE_AUDIO.md` §2.2, `RE_SA_DSP.md` §6). null-SA에선 무음.

## 5. route-b 통합 모델 (동영상)

- **직접 디코드 재구현 = 하지 말 것**: AVC/오디오 디코드는 SA DSP 전용 펌웨어(ZIMA) 상주 + av-cam 메일박스 프로토콜. 우리 주입 프로세스에서 이를 재현/구동하는 것은 공수·위험 모두 비현실적이고, `minimal-sony-footprint` 원칙(Sony 영상/엔진 SW 처리는 그대로 유지)에도 어긋난다.
- **권장: 순정 재생 트리거 + OSD 오버레이**(촬영 패스스루와 동일, `route-b-stock-osd-passthrough`). 우리 UI는
  1. 동영상 항목 선택 시 순정 ViewSinglePb 동영상 재생을 띄우거나(모델트리 전환), 또는 우리 메뉴에서 `MprIf::PlayMovie` 상당을 호출(엔진 접근은 SDCom/휘발 경로로 한정, 벽돌-안전).
  2. 영상은 순정이 ch51로 그린다. 우리는 ch53 OSD만(진행바·시간·우리 컨트롤패널) 그린다.
- **갤러리 썸네일 그리드에서 동영상 셀** = 재생 배지(play badge) + 정지 썸네일만(현 `playback_inproc.cpp`가 동영상엔 비트맵 비표시). 실제 재생은 위 트리거.

## 6. 디바이스 확인 필요 항목
1. 실기에서 동영상 재생 중 funcMode 21 유지/`ViewSinglePb` 동영상 레이아웃 확인, ch51 scanout 주소가 디코드 버퍼로 바뀌는지(HMP/probe).
2. `InfraMovieDecoder` codecID 값 ↔ AVCHD(TS)/MP4 매핑 실측.
3. route-b에서 순정 동영상 재생을 트리거하는 최소 입력 시퀀스(모델트리 전환 vs MprIf 직접)와 그때 입력 소유권/크래시 여부 — 실기 검증.
4. 오디오 출력 라우팅(스피커/HDMI) 실측.

## 7. 근거(심볼/오프셋)
- `MprIf::PlayMovie` libObj+0x31100, `CancelPlayMovie` libObj+0x31610, `EnterMoviePb` libObj+0x2fa4b, `PlayStillSingleByAddress` libObj+0x32996.
- `InfraMovieDecoder`(Create/Destroy/SeqDecStart/SeqDecChgSpeed), `ObjEffect SequenceFactoryComponentMoviePlay`.
- `ObjRenderer SequenceSetTimeCodeCmd` / `ExecCommandVdfSetTimeCodeCmp`.
- VPH ch51 = 에뮬 `RE_DISPLAY_SCANOUT.md`(ch51 panel YUV = live/playback image; ch53 panel OSD).
- SA ZIMA/오디오 = 에뮬 `RE_SA_DSP.md` §6, `RE_AUDIO.md` §2.2.
- 녹화 포맷 노드: `cmnViewSettingNodeMovieFileFormatAVCHD_*`(viewUnified 문자열).
