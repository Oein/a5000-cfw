# 0001. funcevent-mode-enum

상태: 코드-의미 표는 정적 분석 확정, 일부(9/10/11)는 잠정. 모드 3(P)·8(SCN)은 실기 측정.

## 요약
순정 View 관리자가 "지금 최상위 뷰가 어떤 기능 이벤트 모드인가"를 돌려주는 함수가 `viewManagerIf::getCurrentFuncEventMode`(libObj+0x394924)다. 내부적으로 `sub_70A734(dword_EEDDD8)`를 호출해 유효한 최상위 뷰를 찾고, 그 뷰의 vtable+96 슬롯(= 뷰별 `getFuncEventMode`)을 부른다. 반환값이 모드 코드다.

## 코드표
| 코드 | 의미 | 대표 뷰 / 비고 |
|---|---|---|
| 0 | 루트 / 모드 셀렉터 | ViewRootSelector |
| 1 | 촬영(기타/폴백) | 촬영 계열 뷰의 기본값 |
| 3 / 4 / 5 / 6 | 촬영 P / A / S / M | 실기에서 P 라이브 촬영 중 3 확인 |
| 7 | iAuto / 프리미엄 오토 | |
| 8 | SCN(신 모드) | 실기 측정 |
| 9 / 10 / 11 | 파노라마 / 동영상 / 특수 | 잠정(미검증) |
| 21 | 재생 / 이미지 리뷰 | ViewSinglePb, ViewSinglePb4K, ViewStlrec+343 |
| 23 | MENU / 전체 정보 DISP | ViewSettingMenu, ViewShootingInfoDisp |

## 촬영값은 상수가 아니다
`ViewStlrec::getFuncEventMode`(sub_10A32C)는 고정값이 아니라 노출 모드를 읽는다. 테이블 `dword_36E3FC`(0x36E3FC)를 0x12C D-value(노출모드)로 인덱싱해 3~8 등을 결정한다. 따라서 "촬영 중 = 1"로 가정하면 안 되며, 촬영 여부는 {3,4,5,6,7,8,1,...} 집합 또는 {21,23,0}이 아님으로 판정한다.

## 네이티브 UI vs Android 앱 전경
`ScalarAppfwIF::IsViewModeDiadem`(0x7098B8) = `(dword_F13D84 == 0)`.
- 결과 != 0: 네이티브 Sony UI(Diadem)가 전경.
- 결과 == 0: Android/Scalar 앱이 전경.
세터: 0x709874는 1(Scalar)을, 0x709904는 0(Diadem)을 설정한다.

## 활용 지침
촬영 전용 OSD 게이팅: funcMode가 21 또는 23이거나 네이티브가 아니면(IsViewModeDiadem==0) 우리 OSD를 숨기고 순정에 넘긴다. 촬영 중에만 순정 OSD 패스스루/오버레이를 허용한다.
