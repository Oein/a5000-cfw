# 0002. model-camera-read-gate

상태: 게이트 원인 정적 확정, P 모드 라이브 촬영에서 실기 확인.

## 증상
인프로세스에서 모델/카메라 값 읽기는 -1이 나오는데 배터리(POWER)는 정상 읽혔다.

## 원인
호출 체인: `viewManagerIf::getModelInfo`(0x39485C) -> `ViewManager::getModelInfo` -> `sub_706F4C`(0x706F4C).
1. 모델을 **전역 레지스트리**(`sub_7069FA`)에서 찾는다. 현재 뷰 라우팅이 아니다.
2. 모델 객체의 **상태 워드 `model[+8]`이 [0x10001, 0x5FFFF]** 범위일 때만 통과한다. 이 범위는 라이브뷰/촬영 파이프라인 가동 중을 뜻한다.
3. 라이브뷰가 꺼진 대기 상태에서는 범위 밖 -> getModelInfo=0 -> 호출측 -1.
POWER/배터리는 항상 범위 안이라 읽힌다.

## 결론
- 조리개/셔터/노출모드/WB는 뷰 독립 그룹 경로(CVPDM 그룹)가 **없다**. 오직 Path A `getModelInfo`(@M00B)뿐이고 라이브뷰 on일 때만 동작한다.
- ISO는 group 21 폴백이 있다(settings/0002 참조).
- `online()` / READING-CAMERA 표시는 일시적 상태로, 구조상 스스로 복구되며 영구 래치가 아니다.

## 실기 확인
P 모드 라이브 촬영: funcMode=3, camModelReadable=1, 실제 조리개/셔터/ISO 값 수신.

## 필드별 읽기 경로
| 필드 | Wrapper@주소 | selector | 값 소스 |
|---|---|---|---|
| 조리개 | WrapperAperture@0x21C5EC | 52 | 0x1B5 |
| 셔터 | @0x2243E8 | 53 | 0x1B8/0x1B9 |
| ISO | @0x220140 | 72 | 0x1F4 |
| WB | @0x224F24 | 19 | 0x138 |

## 활용
읽기 가능 여부(camModelReadable)를 UI 게이트로 쓰고, 불가 시 값을 "--"로 표시하거나 마지막 값을 유지한다. funcMode(camera/0001)와 함께 쓴다.
